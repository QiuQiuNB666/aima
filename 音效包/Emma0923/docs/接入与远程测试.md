## 路段对应

SCENE-MAP.json 由 state.mjs 的 mixFor() 生成。8 条路线共 66 个路段，区间是游戏 T.pos 的零基 [start,endExclusive)，不是米数或关节角度。

- 珠峰 67 步：营地 / 冰川 / 山脊按路段切换；顶峰减轻风声。冰壁用 ice，横梯 / 中国梯用 metal，台阶 / 横切用 stone，其余用 snow。等待不响脚步。
- 华山 61 步：cliff 风底，长空栈道用 wood，鹞子翻身用 metal，其余用 stone。扣锁等待段不响脚步。
- 东京：原雨 / 车流混音，神社降低音量；cyber_pad 为可选低频层。
- 泰山、富士山、梧桐山：保留原场景设计，按石阶、碎石、落叶匹配。
- 两条训练路线默认静音；试听台明确勾选才出声。
- 跑酷：独立屋顶底音，动作由前端 run.events 触发。试听台中的四个跑酷路段只是人工试听分类，不是游戏距离遥测。

## 主游戏中的替换位置

1. themes/snow_summit/soundscape.js：风 / 炉声替换为对应循环，营地文件已含炉子气流，不再叠加 stove；crunch、ice、ladder、rope、breath、flap 按原触发点换文件。rock 可用原 step_stone。呼吸默认不自动加入。
2. themes/snow_summit/heli.js：rotor 对应 helicopter_rotor.wav，保留距离 × 旋翼速度，不做全局常驻声。
3. themes/snow_summit/yaks.js：yakbell 对应 yak_bell.wav，保留距离衰减，限制同一物体铃声重叠。
4. 地图互动的 click / clink / hiss / flutter：对应扣锁、铁链、氧气、旗帜。扣锁声音仅代表画面互动，不能用来判定真实穿戴安全。
5. themes/cyber_night/gits.js：camo / glitch / taiko 对应同名新文件，保留原事件边缘和冷却。cyber_pad 替换 pad，tokyo.wav 替换雨 / 远处车流底音。
6. parkour/main.js：在现有 run.events 消费处挂 jump、land、slide；low / high / block / fall / wall / caught / corner 共用 parkour_hit，同帧最多一次。parkour/fx.js 的 hum 对应 mech_hum；风底按速度调音量。暂停、重开、退出都停止旧音源。

catalog.mjs 与 SCENE-MAP.json 含 21 项事件、2 个叠层、建议增益。**它们是接入映射，不是已经安装的主游戏补丁。** 替换时停用对应 kit.sfx / sfxLoop，避免两份声音叠播。峰哥、NPC 人声及商业音乐不在本包内。

## 播放接口

```js
import { Soundscape } from '/soundscape/audio.mjs';
import { ProgressGate } from '/soundscape/state.mjs';
const sound = new Soundscape(name => '/soundscape/assets/' + name);
const gate = new ProgressGate();
// 用户点击启用：await sound.start()
// 新状态：const r = gate.accept(S, performance.now())
// r.valid：主题改变才 await sound.switchScene(r.style)，再 sound.setRegion(r.terrain)
// r.step：sound.step(r.material)；!r.moving：sound.stopSteps()
// r.arrive：sound.cue('arrive')
// 实际解说播放开始 / 结束：sound.setNarrationActive(true / false)
// 动作事件：sound.shot('parkour_jump.wav', 0, false, 0.65)
// 状态失效超过 1.6 秒 / 页面隐藏 / 退出：sound.stop(); gate.reset()
```

上面为接口示意，完整可运行示例见 lab.mjs。底音渐入约 0.8 秒，旧源约 0.55 秒内退出。保留异步播放代数，避免迟到下载在停止后又发声。每次只接受进度增加一步；不按步频猜测步数，不补播旧事件。

主服务器尚无 /soundscape 静态路由；集成时补只读路由及 .mjs / .wav MIME，保留路径边界检查。单独试听无需改主游戏：

```sh
python "音效包/Emma0923/tools/serve_soundscape.py" --port 8890 --source http://127.0.0.1:8765
```

代理仅允许本机 GET /state，不转发用户档案、力矩或控制指令。跑酷跟随按钮禁用，因为服务端 terrain 不代表跑酷画面事件。

## 混音与眼镜

默认总音量 25%；实际解说期间环境音压到原值 22%，动作音压到 45%。应连接媒体 play / ended / pause / error，不能用出现一句字幕猜测说话状态。并入游戏时继续遵守 vSfx、?sfx=0 和预览静音。

同源试听页用 BroadcastChannel 互斥；不同电脑 / 不同浏览器来源不会自动互斥。指定唯一音频主机，不要让电视、手机和眼镜同时播三份。页面进入后台停声。

E06s 等眼镜走系统媒体输出。有屏眼镜可复用声音，屏显另行适配；未承诺所有品牌兼容、头部追踪或自动识别输出设备。远程电脑验收：选择眼镜输出 → 左 / 中 / 右声道 → 声画脉冲 → 环境与脚步 → 停步 / 暂停 / 断线停声。确认远程桌面未把声音转到控制端。浏览器时延估计不等于蓝牙端到端时延。

本轮未连接硬件、未读取麦克风、未发送电机指令，也未改变正在运行的主游戏。数字检查可复现；听感、舒适度与 E06s 实机仍待佩戴者验收。
