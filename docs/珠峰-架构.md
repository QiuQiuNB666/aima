# 珠峰北坡 · 专项架构（主打地图）

> 9/23 定：展位默认地图 = 珠峰。评委 7 分钟只够爬一座山，这座山要让人记住。
> 负责线：E（珠峰线）。数据 `shellos/worlds/everest_north.json`，画面 `game/themes/snow_summit.js` + `themes/snow_summit/*`。

## 1. 设计目标

1. **腿上的力 = 屏幕上的山**：每段地形的力都有画面理由（冰壁 → 台阶阻力，中国梯 → 爬梯阻力，北坳 → 吸氧停顿）。
2. **路边有人间**：大本营是个村子，不是一片雪地。帐篷、经幡、牦牛、直升机，走过去会动、会响、峰哥会点评。
3. **越高越难**：天色、风雪、缺氧、人声随海拔变化，玩家不看 HUD 也知道自己在多高。
4. **只读状态，不碰控制**：场景互动只读 `route.at(s)` / `state`，不调任何控制接口。力只由 ShellOS 地形控制器出（安全员把关）。

## 3. 模块分层

```
everest_north.json            路线（kind/steps/label/alt）── 力的唯一来源
        │
snow_summit.js  build()/update()/rigFor()
  ├─ sky.js        天空、太阳、云海（按进度插 PAL.low/high/storm/summit）
  ├─ snow.js       雪粒（storm 强度随海拔 + 大风口）
  ├─ hypoxia.js    缺氧暗角 / 模糊（5300 m → 8849 m）
  ├─ props.js      静态道具几何：帐篷、氧气瓶、经幡、路绳、梯子、觇标、登山者、冰塔
  ├─ camp.js   ★新  大本营村落布局（大帐篷、石碑、玛尼堆、停机坪、晾衣绳）
  ├─ heli.js   ★新  直升机：低模机身 + 旋翼 + 尾桨；三段脚本（开场降落 / 大风口悬停 / 登顶绕飞）
  └─ yaks.js   ★新  牦牛驮队：6–8 头 instanced，沿路外侧下山，玩家靠近时侧让
```

- **触发只看进度**：`const seg = route.at(s)`；脚本按段 `label` 和段内比例触发，**不写死步号**（路线被 AI 改过也能对上，沿用现有 `zonesOf()`）。
- **音效**：直升机旋翼 / 牦牛铃 / 风声 / 喘气，按进度混音。用现有音频通道，`?sfx=0` 关。离开对应段自动淡出。
- **峰哥**：已有的 `seg` 事件在进新段时自动点评地标。大本营、北坳、第二台阶三段在 `brain` 的 FENGGE 提示词里给真实事实提示（例如「中国梯是 1975 年架的」这类事实，只写拿得准的）。
- **HUD（U 线）**：顶部显示海拔（按 `alt` 线性插值）+ 当前段名；登顶结算页写「8848.86 m」。

## 8. 悬崖三段（E 线，9/24；球球：「这雪山一点感觉都没有，最好是在悬崖峭壁上走……加上一个搭梯子过悬崖的环节」）

全在 `snow_summit/cliff.js`，按路段名找（「梯」的平路 / 「刀脊」/「横切 · 栈道」），生成的雪山没有这几段就什么都不做。

| 段 | 画面 | 实现 |
|---|---|---|
| 北坳裂缝·横梯 | 透镜形冰裂缝（沿路 2、横 15）：壁 雪白 → 冰蓝 → 深蓝 → 黑底、往下收窄；两道铝梯并排（化身 0.35 / 影子 −0.5），每道两架首尾绑接 + 缠绳；两侧扶手绳 + 1 m 雪锥 | 地面缝里的三角形删掉，一圈雪沿（5 道环、最外一道沉进地里）盖住锯齿；路面缝上那 4 步缩成一点；梯子顶点着色器往下弯 + 不稳时抖 |
| 大风口·刀脊 | 路面收到 1 m，右侧 ~60° 掉 26，左侧先悬出雪檐（檐下掏空）再往下；坡上一道道岩肋；脊上一根路绳（离雪 0.3） | 入口 3 步收窄过渡；坡面沿段中间的固定方向铺（路在入口拐一点，远处不打折）；地面同一套坐标挖到坡面下 1 |
| 北壁横切·贴壁栈道 | 岩檐 1.4（外 0.6 / 里 0.8）；右边灰岩壁（4 色层理 + 竖裂、2.3 m 处往外探、顶上积雪）；左边深渊掉 38 | 岩壁比顶峰高：刀脊 / 横切这一组离段口 18 → 12 步才溶出来，登顶不画 |

**过梯**（只读 s 和 `/state` 的 `gait.cadence`，不碰控制）：步频 > 110 或站在梯上 > 4 s → 不稳（0 → 1 约 0.6 s）：镜头左右晃 + 滚、梯子抖、峰哥「慢点，一步一档」；连续不稳 2.5 s → 失足：镜头往下一栽 → 黑场（DOM 黑层）0.9 s + 惨叫（`kit.sfx('scream')`，等 M2 加）+ 梯子闷响 → 淡回来，`window.__fgFalls` +1、派 `fg:fall` 事件（HUD 计数归 U）；没失足走过去 →「过了，这是个好事儿啊」。**没做**：化身拉回梯子起点——化身位置归引擎的步进器，跳回去后按 5 步/s 追平，黑场里就追回来了；要做得引擎给「视觉步数暂停」钩子。

**悬崖感**：刀脊 / 横切镜头 1.2 m 高、往外 0.8（悬在深渊上）、FOV +8°（`CAM.edge`，cliff.js 每帧套 FOV）；横梯镜头压到 0.95、往外 1.55、低头（`CAM.xing`）；这两段雾拉开（fogN/F → 14/130）看得见下面；两层雾带（往下 5.5 / 11，噪声随风飘）+ 56 团往上涌的雪雾（广告牌，约 20 s 一轮）；滚石：进刀脊 / 进横切 1.2 s 来一块，之后约 30 s 一块，从前方路沿滚下去、在坡上弹几下（`kit.sfx('rock')`）。
