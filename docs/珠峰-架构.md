# 珠峰北坡 · 专项架构（主打地图）

> 9/23 定：展位默认地图 = 珠峰。评委 7 分钟只够爬一座山，这座山要让人记住。
> 负责线：E（珠峰线）。数据 `shellos/worlds/everest_north.json`，画面 `game/themes/snow_summit.js` + `themes/snow_summit/*`。

## 1. 设计目标

1. **腿上的力 = 屏幕上的山**：每段地形的力都有画面理由（冰壁 → 台阶阻力，中国梯 → 爬梯阻力，北坳 → 吸氧停顿）。
2. **路边有人间**：大本营是个村子，不是一片雪地。帐篷、经幡、牦牛、直升机，走过去会动、会响、峰哥会点评。
3. **越高越难**：天色、风雪、缺氧、人声随海拔变化，玩家不看 HUD 也知道自己在多高。
4. **只读状态，不碰控制**：场景互动只读 `route.at(s)` / `state`，不调任何控制接口。力只由 ShellOS 地形控制器出（安全员把关）。

## 3. 模块分层

```
everest_north.json            路线（kind/steps/label/alt）── 力的唯一来源
        │
snow_summit.js  build()/update()/rigFor()
  ├─ sky.js        天空、太阳、云海（按进度插 PAL.low/high/storm/summit）
  ├─ snow.js       雪粒（storm 强度随海拔 + 大风口）
  ├─ hypoxia.js    缺氧暗角 / 模糊（5300 m → 8849 m）
  ├─ props.js      静态道具几何：帐篷、氧气瓶、经幡、路绳、梯子、觇标、登山者、冰塔
  ├─ camp.js   ★新  大本营村落布局（大帐篷、石碑、玛尼堆、停机坪、晾衣绳）
  ├─ heli.js   ★新  直升机：低模机身 + 旋翼 + 尾桨；三段脚本（开场降落 / 大风口悬停 / 登顶绕飞）
  └─ yaks.js   ★新  牦牛驮队：6–8 头 instanced，沿路外侧下山，玩家靠近时侧让
```

- **触发只看进度**：`const seg = route.at(s)`；脚本按段 `label` 和段内比例触发，**不写死步号**（路线被 AI 改过也能对上，沿用现有 `zonesOf()`）。
- **音效**：直升机旋翼 / 牦牛铃 / 风声 / 喘气，按进度混音。用现有音频通道，`?sfx=0` 关。离开对应段自动淡出。
- **峰哥**：已有的 `seg` 事件在进新段时自动点评地标。大本营、北坳、第二台阶三段在 `brain` 的 FENGGE 提示词里给真实事实提示（例如「中国梯是 1975 年架的」这类事实，只写拿得准的）。
- **HUD（U 线）**：顶部显示海拔（按 `alt` 线性插值）+ 当前段名；登顶结算页写「8848.86 m」。
