## 怎么跑（不用硬件）

```bash
git clone https://github.com/QiuQiuNB666/aima && cd aima
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m shellos.main --sim --force-deadman --ctl terrain --http 8765
```
浏览器开 `http://localhost:8765`（仪表盘，按住「走路」）、`/worlds`（选山 / 造山）、`/game`（游戏屏）。测试：`.venv/bin/python -m pytest -q`。

要接 Claude：见 `docs/架构-v3-完整版.md` 末节「大脑与蜂群」（大脑跑在能连 Anthropic 的机器上，展位 MacBook 走 SSH 反向隧道）。
