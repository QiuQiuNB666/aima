# Q 助理 · 开源二次元版（VRM 候选）说明

2026-09-24。给球球和自建版做 A/B 用的预览线：8 个可再分发、许可清楚的二次元女性 VRM，一个页面切着看，每个都能待机 / 走 / 跑。

- 预览页：`/game/assistant_q/index.html`（`?model=N` 或 `?model=<文件名>`、`?anim=idle|walk|run`、`?cam=front|side|back|30`、`?bg=white|sky`、`?curve=1` 骨骼缩放加曲线）
- 总览图：`docs/提交/截图/asst_q_candidates.png`（每列一个候选：正面 / 侧面 / 跑步中，底下是名字 + 许可 + 面数 / 大小）
- 文件：`shellos/ui/static/models/assistant_q/`（8 个 .vrm + `mixamo_clips.glb` + `LICENSE.txt` + `shrink.py`），`static/game/assistant_q/`（`index.html`、`npc_q.js`、`vendor/three-vrm.module.min.js`）
- 总大小：models 52 MB + vendor 0.16 MB（预算 60 MB）。原件合计 116 MB，全部过了一遍 `shrink.py`（见下「瘦身」）。
- ⚠ `shellos/ui/server.py` 的 `_static` 没给 `.html` 和 `.vrm` 配 MIME（都落到 octet-stream，浏览器不渲染 html）。本线只准新增文件，所以预览要用 `cd shellos/ui/static && python3 -m http.server 8952` 起静态服务看；正式接进 game.html 后 vrm 走 octet-stream 也能被 GLTFLoader 读，只有 html 那一行要主线在 server.py 加 `".html": "text/html"`（一行）。

## 动作：Mixamo → VRM 重定向

- 动作源 `mixamo_clips.glb`（0.5 MB）：three.js 仓库 `examples/models/gltf/Xbot.glb` 去掉网格 / 材质，只留 `idle` / `walk` / `run` 三条 mixamorig 骨骼动画。**没有 Mixamo 账号也拿得到 Mixamo 动作**——Xbot 就是 Mixamo 官方角色。
- 重定向 `retargetMixamo(clip, asset, vrm)`（npc_q.js）照抄 three-vrm 官方 `examples/humanoidAnimation/loadMixamoAnimation.js` 的数学：每根骨 `父骨静止世界旋转 × 轨道旋转 × 本骨静止世界旋转⁻¹`，写到 `vrm.humanoid.getNormalizedBoneNode(骨名)`；髋位移按 `vrm 髋高 / mixamo 髋高` 缩放；VRM 0.x 再翻 x/z。区别只有动作源从 FBXLoader 换成 GLTFLoader（省掉 FBXLoader + fflate 两个依赖）。骨名映射 `MIXAMO2VRM` 去掉了手指（Xbot 三条动作手指几乎不动）。
- 8 个候选走 / 跑 / 待机都正常（总览图第三行就是 run 定格在 30% 处）。VRM0 和 VRM1 混用没问题：`VRMUtils.rotateVRM0()` 把 0.x 的 -Z 朝向转成 +Z。
- 要加指向 / 击掌：Mixamo 网站导出 fbx（Without Skin）→ Blender 转 glb → 追加进 `mixamo_clips.glb`，或者用 VRoid 官方 VRMA 动作包（`@pixiv/three-vrm-animation`，本次没装）。

## 曲线（能不能改比例）

VRoid 系 8 个身体骨骼一样（hips / spine / chest / upperChest…），`curvify(vrm)`（npc_q.js，`?curve=1`）按 assistant_models.md 末尾的骨骼缩放法打在 **raw 骨**上：upperChest (1.25, 1, 1.3)、hips (1.2, 1, 1.2)、spine 收腰 0.88，子骨反向抵消、大腿根 x 除回去。`humanoid.update()` 只拷贝旋转和髋位移，不碰 scale，所以动画不会把它冲掉。

实测（AvatarSample_A `?curve=1`）：臀 / 腰能看出来，胸只是略宽——VRoid 导出的皮肤权重在 spine / chest / upperChest 之间铺得很匀，单骨放大被稀释；再加大会把开衫撑出穿模。**真要明显沙漏，走 VRoid Studio：8 个都有 .vroid 源（CC0 那 4 个随便改），胸围 / 臀围 / 腰围滑块拉完重新导出，5 分钟，无副作用。** Seed-san / Twist Sample 没有 .vroid，只能骨骼缩放或 Blender 改网格。

## 瘦身（shrink.py）

`python3 shrink.py in.vrm out.vrm [MAX=1024]`：缩略图和法线贴图（`*_nml`）换成 1×1 占位，其余贴图长边 ≤1024 重编码为 PNG，重排 BIN；网格 / 骨骼 / 表情 / spring bone / meta 全部原样。效果：VRoid 模型 15 MB → 6–7 MB。要更小：MAX 给 512（脸会糊）或把 `Body_00` 贴图（被衣服盖住大半）再降。`--anim-only in.glb out.glb` 是给 Xbot 剥网格用的。

## 怎么接进 npc.js

`npc_q.js` 的 `makeQ(id, { curve })` 返回和 `game/fengge/body.js` / `npc_jifeng.js` 一样形状的对象：

```js
import { makeQ } from './assistant_q/npc_q.js';
const q = await makeQ('Victoria_Rubin');        // 文件名（不带 .vrm）
scene.add(q.group);                              // 已经朝 +Z、脚在 y=0、身高≈1.6 m（VRoid 默认）
q.update(dt, { speed, dir });                    // 每帧：speed m/s → idle(<0.05)/walk(<1.6)/run 自动切；dir 弧度 = 朝向；里面顺带 mixer.update + vrm.update
q.play('run');                                   // 或手动切，crossFade 0.25 s
q.bones                                          // { hips: 'J_Bip_C_Hips', head: 'J_Bip_C_Head', leftHand: 'J_Bip_L_Hand', … } 18 根 humanoid 骨 → 该模型的实际骨名
q.vrm.humanoid.getRawBoneNode('head')            // 直接拿 Object3D（挂名字牌、看向玩家用 vrm.lookAt.target = camera）
```

- `npc.js` 现在的 `makeJifeng(scene)` 返回 `{ update(dt, pos, dir, dash), … }`，换成 Q 助理只要在 `npc_jifeng.js` 的模型优先级①里加一档：`makeQ()` 成功就用它的 group，`update` 里把 `pos/dir` 写到 `q.group.position / q.update(dt, { speed: 走速, dir })`。台词 / 气泡 / 追逐逻辑不动。**估计 1 小时**：接入 20 分钟、importmap 加 `@pixiv/three-vrm` 一行、server.py 加 `.html` MIME 一行、跟拍镜头下调一次曲线参数 30 分钟。
- 风格对齐：VRM 的 MToon 本身就是卡通哑光，不需要换 MeshLambert；要和峰哥的平面着色统一，`vrm.scene.traverse(m => m.material.shadeColorFactor?.set(…))` 调 MToon 的阴影色即可，别换材质（换了表情 / 描边就没了）。
- 外骨骼不给她穿（`exo: false` 那条路径本来就是 npc_jifeng 的默认）。

## 已知问题

1. **Mixamo 动作的分发许可是灰区**：Adobe FAQ 允许任何付费 / 免费项目使用，禁止把原始动画文件当资源包再分发；`mixamo_clips.glb` 是嵌在游戏里的 0.5 MB 动画数据，和 three.js 仓库自己分发 Xbot.glb 是同一做法。介意的话换 VRoid 官方 VRMA 动作包（VRM 官方格式，随便发）。
2. Seed-san 须署名；AvatarSample_A/B 不得改标 CC0、不得收费分发——写进 `docs/提交/素材授权.md` 时照 LICENSE.txt 抄。
3. 骨骼缩放的胸部效果弱（权重稀释），见上；真要曲线走 VRoid Studio。
4. 面数 25k–45k / 人，比峰哥（~3.4k）高一个量级；swiftshader 无头截图一张 45 s。展位机 GPU 跑一个没问题，别同屏放 3 个以上。`VRMUtils.removeUnnecessaryVertices + combineSkeletons` 已开，再降要 `lod.js` 的 simplify（VRoid 网格有表情 morph，简化会丢表情）。
5. spring bone（头发 / 裙摆）在 `vrm.update(dt)` 里算，`dt` 已夹到 ≤ 0.05 s；掉帧时头发不会炸，但跑步定格截图（`mixer.setTime`）头发是静止姿态。
6. server.py 没 `.html` MIME，预览要用 `python3 -m http.server`（见顶部）。
