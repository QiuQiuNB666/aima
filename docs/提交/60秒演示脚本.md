# 60 秒演示视频脚本

> 用途：官网提交附的演示视频；展位大屏空闲时循环；现场设备出问题时的兜底。
> 素材分两版，**画面上必须标清是哪一版**：
> - **A 版（今晚）**：`--sim` 模拟外骨骼录屏，右下角常驻水印「模拟外骨骼演示」。只有游戏屏 + 仪表盘，没有真人穿戴画面。
> - **B 版（9/24 上午，能拍就换）**：真机穿戴 + 游戏屏分屏。只在 2AFC 做完之后才加「能分辨」字幕，否则不加。
> 节奏对齐展位 4 分钟脚本（架构 v3 第 5 节）的压缩版：看懂 → 腿被推 → 它学会了 → 下一个人继承 → 安全。

## 录制准备（A 版）

```bash
SDL_VIDEODRIVER=dummy .venv/bin/python -m shellos.main --sim --ctl terrain --no-record --force-deadman --http 8765
# 开两个窗口：http://localhost:8765/game（1920×1080 全屏）与 http://localhost:8765/（仪表盘）
# 先让「上一位」爬完一圈，这样开拍时已经有影子：
curl -X POST localhost:8765/wearer -d '{"name":"队友"}'
curl -X POST localhost:8765/sim -d '{"walk":true,"cadence":110}'     # 走；第 4 步进红灯后要停：
curl -X POST localhost:8765/sim -d '{"walk":false}'; sleep 2.5          # 站稳 1.5 s 放行，再 walk=true 走到登顶（东京 37 步）
curl -X POST localhost:8765/wearer -d '{"name":"评委-01"}'            # 换人：步态重估、影子保留（此前没发过反馈，强度仍是缺省 1.5）
```

- **别在录屏机上同时跑 `scripts/shot.sh`**：无头截图会把主循环卡到看门狗 DISARMED（G 线实测）
- 录屏用系统自带录屏（macOS ⇧⌘5），1080p 30 fps 即可
- 经验卡测试会写 `data/experiences.jsonl`，录完 `git checkout data/experiences.jsonl` 还原

## 口径检查（剪完对照一遍）

- A 版全程有「模拟外骨骼演示」水印；旁白只描述控制律的输出（「腿会被轻轻拉住」「髋关节被推一下」，画面里的力矩曲线可证），不说「你能清楚感到」
- 不说「首个腿部力反馈」「首个 VR 外骨骼」；可以说「消费级髋外骨骼、可走动」
- 不说「能分辨坡度」，除非 B 版且 2AFC ≥9/10
- 字幕里的 1.8 Nm 是上台阶主脉冲在缺省强度 1.5 下的峰值（1.2 × 1.5），改了缺省强度要同步改字幕
- 「下一个步频相近的人自动继承」：检索条件是同控制律 + 步频 ±10，换人后走满 6 步才检索——画面上要能看到事件流「命中经验 #n」，看不到就删掉这句旁白。**删完卡一定要点「恢复」**：删掉的卡不参与检索，不恢复就没有下一次命中
