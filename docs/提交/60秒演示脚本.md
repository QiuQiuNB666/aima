# 60 秒演示视频脚本 ·「峰哥亡命天涯」

> 用途：官网提交附的演示视频；展位大屏空闲时循环；现场设备出问题时的兜底。
> 顺序和展位 4 分钟脚本一致：**开场共驾 → 爬山 → 评委说一句改手感 → 一句话造山 → 峰哥解说登顶**。
> 素材分两版，**画面上必须标清是哪一版**：
> - **A 版（9/23–9/24 凌晨）**：`--sim` 模拟外骨骼录屏，右下角常驻水印「模拟外骨骼演示」。只有游戏屏 + 仪表盘，没有真人穿戴画面。
> - **B 版（9/24 上午，能拍就换）**：真机穿戴 + 游戏屏分屏。只在 2AFC 做完之后才加「能分辨」字幕，否则不加。
> **大模型口径**：旁白一律说「大模型」；录制时蜂群时间线里的模型名写着 Claude 才能说 Claude（截至 9/23 下午没有 Claude key，跑的是 MiniMax-M3）。大脑没连上就用本页每段的「兜底旁白」，字幕里换成「规则兜底」。**录完看一眼卡片上的模型名（现在是 MiniMax-M3）/ `rule`和峰哥那条的来源（`claude` / `canned`），和旁白对不上就重录或换旁白。**
> **展位参数**：启动参数 `--cap 4 --strength 3.0 --width 16`（软限 4 Nm、强度 3.0、脉冲底宽 16%），录 A 版也用这组，画面上的力和展位一样。

## 录制准备（A 版）

```bash
SDL_VIDEODRIVER=dummy .venv/bin/python -m shellos.main --sim --ctl terrain --no-record --force-deadman --http 8765 --cap 4 --strength 3.0 --width 16
# 要大模型：另开终端起大脑（ANTHROPIC_API_KEY=Claude，或 brain/.env 写 MINIMAX_API_KEY），展位 MacBook 还要 SSH 隧道，见架构 v3 末节
# 开两个窗口：http://localhost:8765/game（1920×1080 全屏）与 http://localhost:8765/（仪表盘，蜂群时间线露出来）
# 缺省世界就是珠峰北坡（56 步）。先让「上一位」爬完一圈，这样开拍时已经有影子：
curl -X POST localhost:8765/wearer -d '{"name":"队友"}'
curl -X POST localhost:8765/sim -d '{"walk":true,"cadence":110}'     # 走；两处红灯要停：第 30 步北坳吸氧、第 52 步第二台阶排队
curl -X POST localhost:8765/sim -d '{"walk":false}'; sleep 2.5          # 每到红灯停 2.5 s（站稳 1.5 s 放行），再 walk=true，走到登顶
curl -X POST localhost:8765/wearer -d '{"name":"评委-01"}'            # 换人：步态重估、影子保留（强度回启动参数 3.0）
```

- 开场共驾那 6 秒：仪表盘控制律切 `puppet` 录共驾画面，录完切回 `terrain`（切回沿用原来的地形实例，影子还在）
- 造山那段：在 `/worlds` 顶部输入框打字点「造山」，或 `curl -X POST localhost:8765/world/generate -d '{"text":"峰哥坐亡命小飞机降落卢卡拉，徒步七天到珠峰大本营"}'`。造出来的山至少 20 步，爬到顶要剪辑加速（画面角标「×4」），**不许剪掉中间直接接登顶**
- **别在录屏机上同时跑 `scripts/shot.sh`**：无头截图会把主循环卡到看门狗 DISARMED（G 线实测）
- 录屏用系统自带录屏（macOS ⇧⌘5），1080p 30 fps 即可
- 经验卡测试会写 `data/experiences.jsonl`，录完 `: > data/experiences.jsonl` 清空

## 口径检查（剪完对照一遍）

- A 版全程有「模拟外骨骼演示」水印；旁白只描述控制律的输出（「腿被轻轻拉住」「髋关节被推一下」，画面里的力矩曲线可证），不说「你能清楚感到」
- 旁白只说「大模型」；蜂群时间线里模型名是 Claude 才能说 Claude；卡片来源 `rule`、世界说明「规则模板」、峰哥 `canned` 就用兜底旁白
- 峰哥素材（照片贴脸、头像气泡、语录、复刻的峰哥音色）：**峰哥本人 9/23 在现场当面口头同意本次黑客松展示使用他的肖像、口吻和 AI 复刻声音**，成片默认用峰哥版；视频要发到黑客松以外的平台（B 站、小红书等）另外再问。他改主意就用 `/game?fengge=0&voice=0` 重录，旁白和字幕换成「解说员」。峰哥音色出现处打「AI 复刻音色」角标；MiniMax 失败时会退回系统女声，成片里不能有女声念峰哥台词
- 不说「首个腿部力反馈」「首个 VR 外骨骼」；可以说「消费级髋外骨骼、可走动」
- 不说「能分辨坡度」，除非 B 版且 2AFC ≥9/10
- 字幕里的 3.6 Nm 是上台阶阻力脉冲在展位强度 3.0 下的峰值（1.2 × 3.0，`terrain.py`）；上午改了强度要同步改字幕。9/23 以前录的素材是旧手感（上台阶是推），不能用
- 共驾画面：被推的只能是队友（B 版真人镜头同样）
- 「峰哥的影子」：只有 B 版、峰哥本人真在珠峰爬过一圈（影子标签是「峰哥」）时，旁白才能说「旁边是峰哥本人的影子」；A 版模拟录屏的影子是「队友」，不这么说
- 造山段不剪「等待」以外的内容；造山用时 MiniMax-M3 实测 p50 7.0 s、最长 10.0 s（C 线），太长就剪掉等待并加角标「等待已剪」
