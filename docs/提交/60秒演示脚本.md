# 60 秒演示视频脚本 ·「峰哥亡命天涯」

> 用途：官网提交附的演示视频；展位大屏空闲时循环；现场设备出问题时的兜底。
> 顺序和展位 4 分钟脚本一致：**开场共驾 → 爬山 → 评委说一句改手感 → 一句话造山 → 峰哥解说登顶**。
> 素材分两版，**画面上必须标清是哪一版**：
> - **A 版（9/23–9/24 凌晨）**：`--sim` 模拟外骨骼录屏，右下角常驻水印「模拟外骨骼演示」。只有游戏屏 + 仪表盘，没有真人穿戴画面。
> - **B 版（9/24 上午，能拍就换）**：真机穿戴 + 游戏屏分屏。只在 2AFC 做完之后才加「能分辨」字幕，否则不加。
> **Claude 口径**：录制时仪表盘蜂群标题旁显示「大脑 Claude 在线」才能配「Claude 现场……」的旁白和字幕；没连上就用本页每段的「兜底旁白」，字幕里把 Claude 换成「规则兜底」。**录完看一眼卡片来源（`claude` / `rule`）和峰哥那条的来源（`claude` / `canned`），和旁白对不上就重录或换旁白。**

## 录制准备（A 版）

```bash
SDL_VIDEODRIVER=dummy .venv/bin/python -m shellos.main --sim --ctl terrain --no-record --force-deadman --http 8765
# 要 Claude：另开终端 ANTHROPIC_API_KEY=… brain/.venv/bin/python brain/claude_brain.py（展位 MacBook 还要 SSH 隧道，见架构 v3 末节）
# 开两个窗口：http://localhost:8765/game（1920×1080 全屏）与 http://localhost:8765/（仪表盘，蜂群时间线露出来）
# 先让「上一位」爬完一圈，这样开拍时已经有影子：
curl -X POST localhost:8765/wearer -d '{"name":"队友"}'
curl -X POST localhost:8765/sim -d '{"walk":true,"cadence":110}'     # 走；第 4 步进红灯后要停：
curl -X POST localhost:8765/sim -d '{"walk":false}'; sleep 2.5          # 站稳 1.5 s 放行，再 walk=true 走到登顶（东京 37 步）
curl -X POST localhost:8765/wearer -d '{"name":"评委-01"}'            # 换人：步态重估、影子保留（强度回缺省 1.5）
```

- 开场共驾那 6 秒：仪表盘控制律切 `puppet` 录共驾画面，录完切回 `terrain`（切回沿用原来的地形实例，影子还在）
- 造山那段：在 `/worlds` 顶部输入框打字点「造山」，或 `curl -X POST localhost:8765/world/generate -d '{"text":"峰哥被追到泰山顶，一路狂奔上十八盘"}'`。造出来的山至少 20 步，爬到顶要剪辑加速（画面角标「×4」），**不许剪掉中间直接接登顶**
- **别在录屏机上同时跑 `scripts/shot.sh`**：无头截图会把主循环卡到看门狗 DISARMED（G 线实测）
- 录屏用系统自带录屏（macOS ⇧⌘5），1080p 30 fps 即可
- 经验卡测试会写 `data/experiences.jsonl`，录完 `: > data/experiences.jsonl` 清空

## 口径检查（剪完对照一遍）

- A 版全程有「模拟外骨骼演示」水印；旁白只描述控制律的输出（「腿被轻轻拉住」「髋关节被推一下」，画面里的力矩曲线可证），不说「你能清楚感到」
- 旁白里的「Claude」只在蜂群时间线里真出现 Claude 来源时才保留；卡片来源 `rule`、世界说明「规则模板」、峰哥 `canned` 就用兜底旁白
- 峰哥素材（照片贴脸、头像气泡、语录、复刻的峰哥音色）：**峰哥本人 9/23 在现场当面口头同意本次黑客松展示使用他的肖像、口吻和 AI 复刻声音**，成片默认用峰哥版；视频要发到黑客松以外的平台（B 站、小红书等）另外再问。他改主意就用 `/game?fengge=0&voice=0` 重录，旁白和字幕换成「解说员」。峰哥音色出现处打「AI 复刻音色」角标；MiniMax 失败时会退回系统女声，成片里不能有女声念峰哥台词
- 不说「首个腿部力反馈」「首个 VR 外骨骼」；可以说「消费级髋外骨骼、可走动」
- 不说「能分辨坡度」，除非 B 版且 2AFC ≥9/10
- 字幕里的 1.8 Nm 是上台阶主脉冲在缺省强度 1.5 下的峰值（1.2 × 1.5），9/24 上午改了缺省强度要同步改字幕
- 共驾画面：被推的只能是队友（B 版真人镜头同样）
- 造山段不剪「等待」以外的内容；Claude 造山的实际用时**待 9/24 上午实测回填**，太长就剪掉等待并加角标「等待已剪」
