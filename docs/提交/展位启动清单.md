## 真机切换（早上 8765 跑着 --sim → 真机）

**确切命令**（MacBook）：

```bash
cd ~/aima && scripts/booth_up.sh
```

它依次做：停掉旧看门狗 → `run-mac.sh` 停 8765 上的 --sim，按真机参数重起（等于 `./run-mac.sh --ctl terrain --stepping --cap 4 --strength 3.0 --width 16 --http 8765`）→ 起新看门狗 → 重开大屏和仪表盘两个 Chrome → 跑体检。约 40 s。

- 直接敲上面那条 `./run-mac.sh …` 也行。现在 `run-mac.sh` 每次都把参数写进 `/tmp/booth-8765.args`，看门狗之后按真机参数重起。以前会按早上的 `--sim` 重起。它不开 Chrome，Chrome 页面会自己重连。
- 不要带 `--force-deadman`。真机会拒绝启动，报 `--force-deadman 只允许配合 --replay`。
- 切一次影子就丢了（影子在 ShellOS 内存里），所以第 9 条峰哥爬山放在切完之后。

**① 找不到串口**（`ls /dev/cu.usbserial*` 报 `no matches found`）

1. 外骨骼开机了吗，进工作态了吗？没开机时 Mac 看不到 USB 设备。开机后等 5 s 再 `ls`。
2. `ls /dev/cu.*` 看全部。叫 `/dev/cu.usbmodem…` 也能用，ShellOS 这两种都认。
3. 换那根确定能传数据的 Type-C 线，直插 MacBook，不经过 hub。
4. `system_profiler SPUSBDataType | grep -B2 -A8 -i serial`：看得到设备但没有 `/dev/cu.*`，说明是驱动问题；看不到设备，说明是线或口的问题。
5. 串口没好也可以先起。真机模式每秒重试一次串口，插上后 2 s 内自动 ENABLE。这时体检「串口帧率」是红的，按速查 #1 处理。

**② 手柄没连**（`booth_up` 打印 `手柄：没看到 DualSense`，或体检 `[!!] 手柄 不在`）

1. 插 USB-C 线最稳，展位优先用有线。蓝牙就按一下 PS 键。
2. `scripts/booth_recover.sh pad` 等 30 s，出现 `手柄回来了` 就行。
3. 还不行：长按 PS 10 s 硬重启，或者去系统设置 → 蓝牙里断开再连。
4. 实在不行：用仪表盘上的「按住助力」按钮代替 R2（只有 MacBook 本机的网页能按）。

**③ 力矩方向反了**（第 4 条 `probe.py --torque 0.5`，或第 10 条穿戴者说反了）

- `probe.py` 直接占串口。ShellOS 真机在跑时先 `scripts/booth_up.sh --down`，测完再 `scripts/booth_up.sh`。两个进程抢一个串口，读数会乱。
- 两腿都往后推（伸展）：方向对，继续。
- 一条往前、一条往后：右腿镜像约定错了。把 `shellos/device/convention.py` 里的 `R_SIGN = -1.0` 改成 `+1.0`，要总指挥点头；改完 `scripts/booth_up.sh`，再测一次。
- 两条腿同向，都往前抬（屈曲）：「正值 = 伸展」这个推断错了。展位上不改代码，告诉总指挥。今天讲解不说「推 / 拖」，第 11 条的结论也不说。

**④ 切完以后 `scripts/booth_check.sh` 全绿的样子**

```text
展位体检 端口 8765  12:36:10
  [OK] ShellOS  /dev/cu.usbserial-XXXX  控制律 terrain  世界 everest_north  穿戴者 anon
  [OK] 串口帧率 200 Hz  坏帧 0  age 5 ms
  [OK] 手柄   在  R2 0.0
  [OK] 安全   ARMED  软限 4.0 Nm  …
  [OK] 控制环 最大间隔 12 ms（100 Hz 环；Guard >100 ms 清零力矩）
```

## 操作方式切换（评委 / 解说没穿外骨骼也能玩）

三种模式，ShellOS 记着（`/state` 的 `input.mode`），登山和跑酷两页跟着变；**键盘 / 手柄模式腿上一律 0 力矩、步态不计步**，穿着的人原地踏步画面也不动，切回外骨骼才恢复：

| 模式 | 怎么切 | 走路 / 跑 | 其它键 |
|---|---|---|---|
| 外骨骼（缺省） | 设置里选「外骨骼」，或 `?input=exo` | 穿着原地踏步 | 现状不变：R2 出力、跑酷高抬腿跳 / 下蹲滑 / 抬腿保持换道 |
| 键盘 | 登山页 Esc → 设置 → 操作方式 ←→ 选「键盘」；或地址栏 `/game?input=keyboard`、`/parkour?input=keyboard` | 登山：按住 `↑` / `W` / `空格` = 120 步/分匀速，单按一下 = 1 步。跑酷：按住 `空格` = 跑（虚拟步频 150） | 跑酷 `↑` 跳 `↓` 滑 `←` `→` 换道 `A` `D` 转弯；登山 `R` 回山脚 `M` 换山 `V` 视角 |
| 手柄（浏览器读） | 同上选「手柄」，或 `?input=pad` | 登山：左摇杆向前 / 按住 × = 匀速，十字键上 = 1 步。跑酷：左摇杆向前 = 跑 | 跑酷 × 跳 ○ 滑 十字键换道 L1 / R1 转弯 |

- 切换走 `POST /input {"mode":...}`（只认本机，游戏屏和 ShellOS 同一台）；推进走 `POST /drive {"steps":1..5}`，外骨骼模式下返回 `{"error":"exo mode"}`。
- 红灯路段键盘 / 手柄模式一样要「站定」：1.5 s 不按键就放行（最长 6 s 兜底）。
- 登山页右下角小字常显「操作：外骨骼 / 键盘 / 手柄」，跑酷页左下「R2」那行显示当前模式。
- 手柄注意：× 在 ShellOS 自己读的手柄里是急停。手柄模式本来不出力，但同一只手柄接着 ShellOS 时按 × 会把安全层打成 DISARMED（灯变红），换回外骨骼前记得 ○ 重新上膛；要避开就用左摇杆向前。
- 切回外骨骼：步数基线重新对齐，键盘期间穿戴者踏的步不会一下子补上。

## 游戏屏 Chrome：开页面就能出峰哥声音（G 线）

Chrome 默认不让没被点过的页面出声，峰哥导游会先等人按一下键才开讲。`booth_up.sh` 起的两个窗口已经带了 `--autoplay-policy=no-user-gesture-required` 和单独的 `--user-data-dir`（`~/.booth-chrome-8765/game`、`/dash`）。要手动开一个同样能出声的游戏屏：

```bash
open -na "Google Chrome" --args --user-data-dir="$HOME/.fg-kiosk" --autoplay-policy=no-user-gesture-required --start-fullscreen "http://127.0.0.1:8765/game"
```

- `--user-data-dir` 必须单独给一个。Chrome 已经开着的话，同一个配置目录会被交给那个旧进程打开，启动参数不生效。
- 换了配置目录，游戏设置（音量、画质、捷风……）要在这个窗口里重新设一次，设置存在这个目录的 localStorage 里。或者直接写在地址栏里，比如 `?fx=low&npc=0`。
- 检查是不是生效了：页面打开后按 F12 → Console，输入 `__voiceBus.state().unlocked`，应该是 `true`。
- 没用这条命令启动也能用：开页面后按一下字母 / 空格 / 回车，或者点一下屏幕，就解锁了。**Shift / Ctrl / Esc 这类键浏览器不算。**没解锁时画面下方会出「🔈 按任意键开启峰哥声音」。

## 出问题时看哪里

先 `scripts/booth_check.sh`（10 项红绿）或 `scripts/booth_recover.sh`（自动判症状：shellos → exo → 安全 → pad → brain → chrome）；一页纸在 [故障速查](故障速查.md)。游戏页 F12 → Console：

- `__guide.state()`：导游状态。armed = 等人听，playing = 在讲，done = 讲完 / 被打断 / 这一位跳过。
- `__guide.log`：导游每一步的记录。
- `__voiceBus.state()` / `__voiceBus.log`：峰哥声道现在谁在说、有没有解锁。
