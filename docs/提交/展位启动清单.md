# 展位启动清单

## 游戏屏 Chrome：开页面就能出峰哥声音（G 线）

Chrome 默认不让没被点过的页面出声，峰哥导游会先等人按一下键才开讲。展位上的游戏屏用下面这条命令启动，开页面就能出声：

```bash
open -na "Google Chrome" --args --user-data-dir="$HOME/.fg-kiosk" --autoplay-policy=no-user-gesture-required --start-fullscreen "http://127.0.0.1:8765/game"
```

- `--user-data-dir` 必须单独给一个。Chrome 已经开着的话，同一个配置目录会被交给那个旧进程打开，启动参数不生效。
- 换了配置目录，游戏设置（音量、画质、捷风……）要在这个窗口里重新设一次，设置存在这个目录的 localStorage 里。或者直接写在地址栏里，比如 `?fx=low&npc=0`。
- 检查是不是生效了：页面打开后按 F12 → Console，输入 `__voiceBus.state().unlocked`，应该是 `true`。
- 没用这条命令启动也能用：开页面后按一下字母 / 空格 / 回车，或者点一下屏幕，就解锁了。**Shift / Ctrl / Esc 这类键浏览器不算。**没解锁时画面下方会出「🔈 按任意键开启峰哥声音」。

## 部署前查一下峰哥语音缓存

在开发机主工作区：

```bash
python3 -m shellos.agent.guide --check
```

缺了的话先 `python3 -m shellos.agent.guide --tts` 补齐（MiniMax 按字数计费，缺几句花几分钱），再 `./deploy.sh`。ShellOS 启动时也会打印一遍缺哪几句（`guide.check(fill=True)`）。

## 出问题时看哪里

游戏页 F12 → Console：

- `__guide.state()`：导游状态。armed = 等人听，playing = 在讲，done = 讲完 / 被打断 / 这一位跳过。
- `__guide.log`：导游每一步的记录。
- `__voiceBus.state()` / `__voiceBus.log`：峰哥声道现在谁在说、有没有解锁。
