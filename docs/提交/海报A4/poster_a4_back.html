物理反馈，不是视觉反馈。

VR、体感、跑步机游戏都只骗眼睛：画面加手柄震动，腿是空的。我们把一台量产的消费级髋外骨骼（Hypershell）改成腿部力反馈外设：原地迈步，屏幕里的你在爬珠峰北坡，坡和台阶变成腿上真实的阻力和助力。游戏是载体，主角是自研的外骨骼控制软件 ShellOS——官方 App 禁用了这个型号，控制层从串口协议起全是自己写的。

①

穿上，按住 R2

髋外骨骼腰带一扣、两条腿一绑。手柄 R2 是死人开关，松手力矩立刻归零。

②

原地迈步

183 Hz 髋角数据算出步态相位；每一步推进游戏一步，步频就是你的速度。

③

腿上有力

上坡有人从后面推一把，上台阶腿发沉，下台阶落阶一记冲击，红灯轻拉让你站定。

ShellOS 五层跑在一台笔记本上 · 没有外骨骼也能 --sim 全跑

0 设备

真机串口 / 模拟外骨骼 / 录制回放同一接口，上层无感。

1 安全层 Guard

唯一能写串口的地方：软限 4 Nm（固件硬限 7.5 永远不用满）、斜率限 50 Nm/s、死人开关、步态置信度 < 0.5 出力为零、看门狗 100 ms 归零、1 s 直接 DISABLE、急停后必须手动重新上膛。

2 步态估计

髋角极角相位；用真机录制的 12 段数据扫了 1080 档门限，坐 / 站假周期 13 → 0。

3 地形控制律

世界是一份 JSON：平地 / 上坡 / 下坡 / 上台阶 / 下台阶 / 红灯。按路段在步态相位上打梯形髋力矩脉冲，一份 JSON 加一座山。

4 界面

Three.js 登山游戏、选山 / 造山页、操作员仪表盘。大屏左下「腿上的力」画的是实际发给电机的力矩指令，不是动画。
