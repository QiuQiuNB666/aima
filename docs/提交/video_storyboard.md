# 60 秒视频分镜表（拍摄用）

> 这是 [60 秒演示脚本](60秒演示脚本.md) 的拍摄版：顺序、旁白、口径都以那份为准，这里只多写**每个镜头的素材从哪儿录**。
> 顺序：**共驾 → 爬山 → 说一句改手感 → 一句话造山 → 峰哥解说登顶 → 安全收尾**。
> 版本：**A 版** = `--sim` 模拟外骨骼录屏，右下角全程水印「模拟外骨骼演示」；**B 版** = 9/24 上午真机补拍，替换标 B 的镜头。
> 峰哥素材（照片贴脸、大屏头像、峰哥口吻的解说词、复刻的峰哥音色）：**峰哥本人 9/23 在现场当面口头同意本次黑客松展示使用他的肖像、口吻和 AI 复刻声音**，成片默认峰哥版；视频要发到黑客松以外的平台另外再问。他改主意时，游戏地址用 `?fengge=0&voice=0`（关头像、气泡、贴脸和峰哥音色），镜头 8 的旁白和字幕换成「解说员」。

## 录制环境

```bash
# 录屏机上（不要在展位机、有人穿着的时候录）
SDL_VIDEODRIVER=dummy .venv/bin/python -m shellos.main --sim --ctl terrain --no-record --force-deadman --http 8765 --cap 4 --strength 3.0 --width 16
# 游戏页地址都加 &fx=off：lighting.js 的后期管线在 Apple GPU 上会黑屏闪烁（L 线在修），和展位保持一致
# 要大模型的镜头：另开终端起大脑（见架构 v3 末节；Claude 或 MiniMax，看 /health 的 backend）；仪表盘顶栏大脑灯亮才算
```

- 窗口：游戏 `http://localhost:8765/game` 1920×1080 全屏；仪表盘 `http://localhost:8765/` 1440×900；选山 `http://localhost:8765/worlds`
- 录屏：macOS ⇧⌘5，1080p 30 fps
- **不要同时跑 `scripts/shot.sh`**，无头截图会把控制循环卡到看门狗 DISARM
- 声音：解说用的是 MiniMax 复刻的峰哥音色（参考音频：YeJe-cpu/talk-to-fengge，Apache-2.0，约 45 秒公开直播片段）。11 句兜底语录已预生成，断网也出峰哥音色；Claude 现写的新句子实时合成，实测一句 4.2–10.2 s，会比气泡晚出声。MiniMax 失败会退回 macOS `say` 女声——**成片里出现女声念峰哥台词要剪掉或重录**。峰哥音色出现的地方打角标「AI 复刻音色」。录备用版加 `?voice=0`
- `?preview=` 离线预览：只摆静态画面、不连控制循环，HUD 左下角会写「离线预览」，用时 / 最佳这些数是示例。拿来补空镜可以，不能当实测画面讲
- 录完清空经验卡：`: > data/experiences.jsonl`（跟踪文件，也可以 `git checkout data/experiences.jsonl`）

先让「上一位」爬完一圈，开拍时就有影子：

```bash
curl -X POST localhost:8765/wearer -d '{"name":"队友"}'
curl -X POST localhost:8765/sim -d '{"walk":true,"cadence":110}'     # 第 4 步进红灯：
curl -X POST localhost:8765/sim -d '{"walk":false}'; sleep 2.5         # 站稳 1.5 s 放行，再 walk=true 走到登顶（东京 37 步）
curl -X POST localhost:8765/wearer -d '{"name":"评委-01"}'
```

## 剪完对照

- A 版全程水印；离线预览的空镜不配「实测」「真实用时」这类话
- 旁白只说「大模型」；时间线里的模型名是 Claude 才能说 Claude（现在是 MiniMax-M3），否则换 [60 秒演示脚本](60秒演示脚本.md) 里的兜底旁白
- 峰哥头、大屏头像、峰哥口吻解说、峰哥音色、「蜂群文化」那句：已获本人同意，可以留；峰哥音色出现处打「AI 复刻音色」角标；成片里不能有女声念峰哥台词
- 不说「首个」「能分辨坡度」（2AFC ≥9/10 之前）「峰哥本人配音」
- 字幕「峰值 3.6 Nm」对应展位强度 3.0（上台阶阻力 1.2 × 3.0）；9/23 下午之前录的台阶素材是旧手感（上台阶是推），不能用
