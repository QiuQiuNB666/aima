# 演示视频 · 制作说明（V3 视频线，9/24 上午）

> 方案依据：`scratchpad/demo_video_plan.md`（调研 + 分镜）、[60秒演示脚本.md](60秒演示脚本.md)（口径）、[video_storyboard.md](video_storyboard.md)。官方对视频**没有要求**，视频是给评委走到展位前看的，自定 60 s 正片 + 90 s 加长，1080p30 H.264，≤ 50 MB。

>
> **口径（9/24 球球）**：现在的 VR / 体感游戏只有视觉反馈，几乎没人做物理反馈；我们做登山走路的物理反馈——屏幕上的坡和台阶，会真的变成你腿上的阻力和助力。峰哥口吻：「VR 只骗眼睛，这玩意儿骗腿，这是个好事儿啊。」前 10 s（S01 旁白 00 + R03 旁白 02b）和结尾（T99 旁白 11b + 副题「骗腿，不骗眼睛」）都说到；真人腿部特写（实拍位）+ 腿上的力波形 HUD（R05b 特写）+ 上坡 / 台阶力脉冲镜头多给。

## 1. 一句话流程

```
~/黑客松-EvoTavern/视频素材/frames/<镜头>/（无头 Chrome 连拍：jpg + times.txt + events.jsonl）─┐
~/黑客松-EvoTavern/视频素材/raw/B0x.mov（实拍，可选）                                        ├─ scripts/shot_windows.py → build/shots.env
~/黑客松-EvoTavern/视频素材/vo/*.wav、vo/game/*.wav（峰哥克隆声：旁白 + 游戏内台词同期声）     ├─ V=3 scripts/cut_demo.sh ─► v3_60s.mp4 / v3_90s.mp4
~/黑客松-EvoTavern/视频素材/music/*.mp3（CC BY 配乐）                                        ─┘       └─ 片段/字幕版、片段/干净版（交剪映）
```

`scripts/cut_demo.sh` 只依赖 ffmpeg + 系统 python3（PIL 出字幕 PNG，字体 PingFang SC；这台机器的 ffmpeg 8.1 没编 drawtext，字幕 / 水印 / 角标全是透明 PNG overlay）。每个镜头的画面来源按优先级：`raw/<镜号>.*` 实拍 → `clip|<frames>|起|止[|倍速[|裁切]]` 连拍时间窗 → 截图 Ken Burns → 占位卡。连拍只有几 fps，`minterpolate`（运动补偿）补到 30 fps；`MI=blend` 快但糊。

同期声怎么对上：`scratchpad/rec2.mjs` 连拍时每帧顺手记 `#fg` 气泡文字（events.jsonl），`build/clip.py` 在时间窗里看到气泡文字变化，就向 `brain/tts.py`（127.0.0.1:8791，已缓存的直接给）要同一句的峰哥 wav，按 `(气泡毫秒 − 窗起点) / 倍速` 摆进这一段；`scripts/shot_windows.py` 再用这些事件反推每镜的起点（直升机 = 「小飞机」气泡前 4.6 s，让旁白 02b 先说完；吸氧 = 第一个 wait 路段前 3.5 s；登顶 = body.summit 前 2 s）。

配乐：`music/Our Story Begins.mp3`（Kevin MacLeod，CC BY 4.0，见 [素材授权.md](素材授权.md)），−5 dB 垫底，人声总线做 sidechain（`sidechaincompress` threshold 0.05 / ratio 3 ≈ 旁白时压 12 dB），整体 loudnorm −16 LUFS。
