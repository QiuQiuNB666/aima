# 4 分钟展位脚本（每位评委 7 分钟 = 4 介绍 + 3 问答）

> 对齐架构 v3 第 5 节。评委约 30 位逐展位走，每位约 7 分钟，至少 3 位评委打分（官方材料）。
> 角色：**球球**（讲解 + 操作员，站 MacBook 旁）· **穿戴者**（开场是队友，之后换评委）· 可选第三人管大屏和手柄。
> 两块屏：**大屏 = 登山游戏 `/game`**（评委看）；**MacBook = 仪表盘 `/`**（操作员看）。
> 口径：标「待真机验证」的话，9/24 上午没验过就**不说**，按括号里的备用说法讲。

## 时间不够怎么砍（从上往下砍）

1. 共驾开场（直接从 0:40 开始，省 40 s）
2. 红灯（开场前在 `/worlds` 选泰山十八盘或「训练场·台阶」，一上来就是台阶）
3. 登顶：没走到顶就讲「登顶的那一圈会成为下一位的影子」。注意代码行为（`demo_reset`）：**只有还没有任何影子时**，没爬完的这一圈才留作影子；已经有影子就保留原来那位，不说「您就是下一位的影子」

**不砍**：评委亲自穿 + 按扳机 · 说一句话 → 卡片 → 变化 → 删卡回退 · 主动讲安全。

## 节奏估算（待真机验证）

- 东京 37 步。模拟下每一步都被接住；真人步只被接住约 44%（A 线回放，1 人），按步频 108 估：37 步约需 80 步真实踏步 ≈ 45 s，加红灯 2 s + 停顿。**1:10–2:50 这 100 s 大概够一圈**，真机上 9/24 上午掐表。
- 太慢：换短路线（训练场·台阶 25 步）；太快：在 2:50 前多说一句，别让评委干等。

## 现场出问题

| 情况 | 做什么 | 说什么 |
|---|---|---|
| 设备复位 / 掉使能 | 什么都不用做，控制栈 2 s 内自动重新 ENABLE（设备复位的逻辑真机写过，拔线重连**未真机验证**） | 「设备刚复位了，您看状态灯——它自己重新使能了，力矩从 0 重新爬。」 |
| 状态 DISARMED（看门狗 / 急停） | 仪表盘「重新上膛」或手柄 ○ | 「这是看门狗——控制循环卡了一下，它直接断了使能。安全层在工作。」 |
| 评委感觉不到脉冲 | 仪表盘把 strength 调到 2.5（≈上台阶 3 Nm 峰值）；或切「训练场·台阶」 | 不说「能感到地形」，改说「腿上的触觉提示随地形变化」 |
| 原地踏步相位不稳（化身不走） | 让评委慢一点、步子大一点；实在不行改慢走 | 「它只在确认您在走的时候才给力——站着晃不会有脉冲。」（置信度门控） |
| 外骨骼没电 / 彻底不行 | 切模拟：`./run-mac.sh --sim --ctl terrain --force-deadman`，网页按住「走路（模拟）」；或放 60 秒视频 | 「设备没电了，这是同一套软件接模拟外骨骼」——**明说是模拟** |

## 说错会扣分的话（不说）

- 「首个腿部力反馈 / 首个 VR 外骨骼」——Holotron 2020 就有
- 「用户能分辨坡度」——**只有 2AFC ≥9/10 之后才说**，否则说「我们做了蒙眼二选一实验，结果是 x/10」
- 「Hypershell 官方开放接口」——说「黑客松专用固件 + 现场发的串口协议」
- 「医疗 / 康复器械」——说「非医疗消费设备；康复游戏化是远期方向」
- 「我们的算法比 Hypershell 的准」——说「我们站在它上面做应用层和记忆层」
