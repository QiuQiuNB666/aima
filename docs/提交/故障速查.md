# 故障速查 · 一页纸（症状 → 30 秒动作）

> 先看仪表盘右上角的状态，再对症。不确定就 `scripts/booth_recover.sh`（自动判断）或 `scripts/booth_check.sh`（10 项红绿）。
> 网络类问题**先查底层再猜应用**：`curl -sI 127.0.0.1:8790/health` 拒绝连接 = 隧道没起；通了再看 /health 内容。

| 症状（你看到的） | 原因 | 30 秒动作 |
|---|---|---|
| 大屏人物不动、仪表盘「没帧 / age 涨」，安全状态 DISCONNECTED | 外骨骼掉电 / 串口断 | 外骨骼关机 → 数 3 秒 → 开机进工作态；线不用拔。`scripts/booth_recover.sh exo` 盯着它回来（每秒重试串口，回来 2 s 内自动重新 ENABLE）。40 s 还没帧：换线 / 换 USB 口 |
| 按 R2 没力，仪表盘 pad=n | 手柄睡了 / 蓝牙断 | 按 PS 键（或插 USB 线）；`scripts/booth_recover.sh pad` 等它认到。30 s 没认到：长按 PS 10 s 硬重启。实在不行：仪表盘上的死人开关按钮代替 R2 |
| 安全状态 DISARMED，「watchdog」或「estop」 | 急停 / 主循环卡过 1 s / 串口刚断过 | 先确认穿戴者站稳 → 手柄 ○ 或仪表盘「重新上膛」。反复 DISARMED：`scripts/booth_check.sh` 看控制环 loop ms；>100 ms 说明本机太忙（别开录屏 / 截图脚本） |
| 蜂群卡片标 `rule` / `canned`，仪表盘「连不上大脑」 | 隧道断或开发机大脑没起 | **演示照常**（规则兜底、导游用本地语音缓存），不要重起 ShellOS。`scripts/booth_recover.sh brain` 告诉你是隧道断（开发机跑 `brain/run.sh`，自动重连）还是大脑没起。旧隧道占端口：`lsof -i :8790` 杀掉 |
| 峰哥没声音，只有气泡 | TTS 缓存缺这句 + 隧道断 | 不影响流程。开发机 `python3 -m shellos.agent.guide --tts && ./deploy.sh` 补缓存；或修隧道后 ShellOS 自动后台补 |
| 仪表盘 / 大屏一起断、`curl 127.0.0.1:8765/state` 不通 | ShellOS 崩了 | 看门狗 1 s 内自动重起并恢复世界 + 穿戴者，等 5–10 s 刷新页面。没起来：`scripts/booth_recover.sh shellos`。日志 `tr '\r' '\n' < /tmp/shellos.log \| tail -20`。**影子会丢**，让队友再爬一圈 |
| ShellOS 在，但大屏卡死 / 黑屏 / 不刷新 | Chrome 卡 | `scripts/booth_recover.sh chrome`（只重开两个窗口，ShellOS 不动）。亭模式退出：Cmd+Q |
| 大屏有画面但一顿一顿 | Chrome 掉帧 / 机器忙 | 大屏地址加 `?debug=1` 看 fps；关掉多余窗口；`/game?auto=1` 自动降光影 |
| iPad 打不开仪表盘 | 不在同一局域网 / IP 变了 | MacBook `ipconfig getifaddr en0`，iPad 开 `http://<IP>:8765/`；iPad 只能看，按钮全 403 是正常的 |
| 换人后强度不对 | 上一位的参数带过来 | 仪表盘换人（参数回缺省 3.0 / 软限 4）；或 Options 演示复位 |
| 世界不对 / 想回珠峰 | 切错了 | `/worlds` 页点珠峰北坡；或 `curl -X POST localhost:8765/terrain -d '{"preset":"everest_north"}'` |
| 全部乱了，重来 | — | `scripts/booth_up.sh --down && scripts/booth_up.sh`（40 s 内起完，只动 8765 这一套）|

## 常用一行

```bash
scripts/booth_check.sh                 # 体检 10 项
scripts/booth_recover.sh               # 自动判断症状（exo / pad / brain / shellos / chrome）
tr '\r' '\n' < /tmp/shellos.log | tail -20         # ShellOS 日志
tail -5 /tmp/booth-8765.watchdog.log               # 看门狗做了什么
curl -s 127.0.0.1:8765/state | python3 -m json.tool | head -40
```
