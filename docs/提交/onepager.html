峰哥亡命天涯

原地迈步，腿上爬山

穿上量产的消费级髋外骨骼原地迈步，屏幕里的你在爬山，坡和台阶变成腿上按步态相位打的力。你说一句「太陡了」，它当场改、记住、传给下一个人；再说一句话，Claude 现场造一座山，安全员裁剪后马上能爬。

代码与技术说明
github.com/QiuQiuNB666/aima

体验流程：4 步，一共约 4 分钟

1

穿上，按住扳机

队友帮你穿好。按住手柄右扳机（R2）才有力，松手立刻归零。开场可以先拿摇杆「推」队友的腿走两步（共驾，被推的只能是队友）。

2

原地踏步，爬山

大屏上的你在爬赛博东京：红灯走也不前进、腿被轻轻往回拉；上天桥台阶，每一步刚落脚髋被推一下、抬腿再帮一下。

3

说一句，改手感

「太陡了」→ 当场变轻，存成经验卡；删卡立刻回到原样。下一个步频相近的人，走满 6 步自动继承。

4

说一句，造一座山

随口说一座山 → 地形导演出路线 → 安全员裁剪 → 马上能爬。登顶时峰哥解说员来一句「这是个好事儿啊」。

技术架构：腿上的安全链路和大模型完全分开

红色 = 能碰到人身上的那一道：Guard 在最底层，安全员在 Agent 层，两道都是确定的代码。大模型只出「提议」，脑子整个拔掉，游戏、腿上的力、经验卡照常工作。

峰哥亡命天涯 · ShellOS · 展位一页纸（正面）口径：数字都标了来源，没在真机验过的写在背面「待实测」

闭环学习：说一句 → 学会 → 传下去 → 能撤销

  1. 评委说「太陡了」
  2. 教练提议 strength −0.5（参数名只能从白名单里选，一次最多改范围的 15%）
  3. 记忆员查同步频段的旧卡：「这个步频段第一次有人这么说，记成新经验」
  4. 安全员「幅度在软限以内，放行」（超了就裁，30 s 内第 4 次改同一参数就否决）
  5. 生效强度 1.5 → 1.0，存成经验卡 #1：穿戴者、步频区间 ±10、差值、原话、来源
  6. 下一个人：换人后走满 6 步、步频落在区间里 → 事件流「命中经验 #1」，自动套用
  7. 删卡 = 回退：删掉已套用的卡，参数立刻反向回到原样——写死的剧本做不到
造山同理：「峰哥亡命天涯，要陡，还要下山」→ 地形导演出 53 步路线 → 安全员「『下山台阶』台阶改成坡：台阶不超过一半，腿受不了」→ 切过去马上能爬。

诚实说明：哪些验过，哪些还没有

真机（9/22）串口握手 PING → VERSION → ENABLE；183 Hz 数据流；力矩指令被接受（OK,T 323 条）；控制循环最大间隔 12 ms、一拍 <1 ms；看门狗触发两次，都按设计断使能
回放（真机录制）穿戴坐站的假步态周期 13 → 0；走动段步子接住率 0.25 → 0.44（游戏里会一顿一顿）；红灯停步到放行中位 2.2 s；12 段录制全栈回放 0 次断使能
模拟 / 单测5 种脉冲形状核对全过、27 组参数边界 0 组不过；11 种故障注入全过；蜂群：安全员裁剪 / 否决 / 急停全否，恶意路线草稿被裁成能走的山，断网兜底全通（不打真 Claude）；游戏 1080p 50–58 fps（开发机）
待 9/24 上午实测力矩方向（「正 = 髋伸展」目前是数据推断）；脉冲穿在身上的手感；脚跟着地在相位的哪里；原地踏步稳不稳；蒙眼二选一（≥9/10 才说「能分辨坡度」）；陌生人穿脱时间；展位 MacBook 帧率；Claude 实连的准确率、造山质量和延迟
