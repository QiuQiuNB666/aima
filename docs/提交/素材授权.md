# 素材授权

> 每条线用到外部素材（模型、贴图、声音、字体、代码片段）就在这里记一行：用在哪、来源、许可证、有没有改。没把握的不用。

| 素材 | 用在哪 | 来源 | 许可证 / 依据 | 备注 |
|---|---|---|---|---|
| CesiumMan.glb | 玩家化身、影子、追兵 NPC「疾风」的底模（`static/models/CesiumMan.glb`） | Khronos glTF Sample Models（CesiumMan） | CC BY 4.0（© 2017 Cesium，带商标限制：不用 Cesium 的名字和 logo） | 原有素材。J 线只是换装：分区纯色、加白发 / 衣领 / 亮边几何体，没有改 glb 文件 |
| 追兵 NPC「疾风」造型 | `static/game/npc_jifeng.js` | 原创（代码生成的几何体） | 自有 | 致敬「风系、白发、蓝色短外套、风刃、冲刺拖尾」这一类角色，**不是**任何游戏角色的模型、贴图、名字、台词或 logo。Riot 的 Legal Jibber Jabber 不允许在游戏和应用里用他们的 IP，所以没有用网上从游戏里提取的模型（Sketchfab 上的都属于这种，或者来源不明）。考虑过 Quaternius Universal Base Characters（CC0），但没用：多一个 glb，骨骼名也不同，接不上现有的 pose |
| 追兵 NPC 语音 | `/voice/npc.wav`，缓存在 `data/voice/npc/`（不进 git） | MiniMax 语音合成 **系统预设音色** `Chinese (Mandarin)_Crisp_Girl`（官方文档「系统音色列表」） | 按量付费的 API 输出，账号是我们自己的 | **没有**克隆任何真人（包括原角色的配音演员），也没用从游戏里提取的音频。台词原创：风起了 / 别停 / 追上你了 / 等等我 / 抓到你了 / 被你甩掉了。9/23 生成一次，一共 42 个计费字符 |
| 角色名「疾风」 | `npc_jifeng.js` 里的 `角色名` | 原创代号 | 自有 | 要改名就改这一个常量，或者临时用 `?npcname=` |
