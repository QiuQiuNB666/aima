# 捷风 · 现场录音台词单

> 全是我们原创的台词。**不念游戏里的任何原台词**。录完放进主工作区 `data/voice/npc_raw/`，切句、归一化、放进游戏都由 J 线来做。

| # | 什么时候说 | 台词 | 情绪 / 语气 |

## 自由说话 30–60 秒（复刻用的参考音频，单独存一个文件）

用平时说话的状态聊，别演、别念台词，也**别念游戏里的台词**。可以聊：今天怎么来的深圳、最近在忙什么、午饭吃了什么、第一次配音是什么感觉。语气自然有起伏，中间别停太久。

## 录音要求

- 用手机自带的录音 App 就行（iPhone「语音备忘录」要把「增强录音」关掉），**不开降噪、变声、混响**。
- 找安静的地方：关窗，离空调、风扇、人声远一点。展位太吵就去走廊或者楼梯间。
- 嘴离手机 20–30 cm，别正对着麦克风吹气；先试录一句，听一下有没有爆音、有没有太小声。
- 文件怎么录，二选一：
  - **一句一个文件**（最好）：按编号命名 `01.m4a` … `11.m4a`，自由说话存 `free.m4a`。
  - **整段一口气录**：按编号顺序念，句与句之间停 **2 秒**，每句念 2 遍，J 线按停顿来切。自由说话还是单独存一个文件。
- m4a 或 wav 都行。放进主工作区的 `data/voice/npc_raw/`（这个目录不进 git）。
