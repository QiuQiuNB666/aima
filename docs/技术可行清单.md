### 1. Hypershell X MaxS 外骨骼（资料最全，能力最硬）

| 能力 | 状态 | 说明 |
|---|---|---|
| 读身体运动数据，200 Hz | ✅ | 插 Type-C 就是串口，`ENABLE` 后每秒 200 行文本：腰部姿态角、陀螺仪、加速度、气压、左右髋关节角度和角速度。Python `pyserial` 按行读、逗号拆即可 |
| 左右腿分别给助力 | ✅ | `T,左,右`，±7.5 Nm，10–500 Hz 续发。100 ms 不续发自动清零 |
| 步态相位估计 | ✅ 有开源 | 极角法：相位 = atan2(k·髋角速度, 髋角−均值)，步间不跳；TUM hip-controller（Python，MIT）可直接改。见 [调研/设备/外骨骼步态相位与助力调参.md](调研/设备/外骨骼步态相位与助力调参.md) |
| 助力（真正的"助行"） | ✅ 有先例 | **不识别相位也行**：延迟输出反馈 DOFC，力矩 = 增益 × 一段时间前的髋角状态，三个参数，三星 2019 实测代谢降 13.6%。延迟量原文没核到，从 0.15 s 起扫 |
| 「评委说早一点」→ 参数改 → 再走就顺 | ✅ 有依据 | 文献里每种参数条件走 20–25 s 就能感知差异；11 人自己调参平均 11 分钟找到偏好。演示用峰时 ±5% 周期、峰值 ±1 Nm 一档 |
| 读电机实际力矩 / 电流 | ❌ | 数据帧里没有，只有角度和角速度 |
| 电池状态 | ❌ | 协议里没有 |
| 充电 | ⚠️ | 官方：USB-C 65 W，72 Wh，博主实测笔记本充电器一个多小时充满；**黑客松固件下能不能充没验证**。官方称 15 秒穿戴 |

## 二、组合能做出的东西（按稳定度排）

### A. 外骨骼 + 手柄 + Mac：会学的助行外骨骼 ✅ 最稳

- 手柄扳机按多深助力多大，松手即 `DISABLE`——安全开关在评委自己手里
- Mac 实时画髋角曲线 + 步态相位，就是评分表点名的「监控/可视化界面」
- **闭环学习怎么演**：评委穿上走两步 → 缺省参数助力时机不对（评委能感觉到"顶脚"）→ 评委说"早一点 / 轻一点"或用手柄微调 → 大模型把这句话写成结构化参数差值，屏幕弹出经验条目 → 再走两步顺了 → 删掉经验又回到顶脚
- 关键路径全在串口和 USB 上，不碰 Wi-Fi，不怕灯光噪声
- 风险：力矩加在人身上，每个参数都要从小值试；穿脱一次要多久没数据（影响 7 分钟脚本）

### B. 眼镜 + Mac：看一眼问大模型 ✅ 蓝牙路径稳，真机未验证

- 触摸板单击 → 拍照 → 11 KB 小图 → 视觉模型 → 眼镜扬声器念答案
- 全程蓝牙，不碰眼镜热点
- 风险：真机还没连过；小图分辨率看小字够不够要实测；扬声器在 Livehouse 里听不听得见要实测

### C. 眼镜 + 外骨骼：眼睛看路、腿给力 ⚠️ 两条稳路径的叠加

- 眼镜拍到"前方有台阶 / 坡"→ 大模型判断 → 外骨骼切换助力模式；或反过来，外骨骼数据判断"在上楼"→ 眼镜念提醒
- 每一段单独都成立，叠起来的时延（拍照 1 秒 + 模型 2–3 秒）意味着只能做"提前提示"，做不了实时反应
- 这是最贴 "Ghost 换 Shell" 主题的组合：同一个 Ghost 同时有眼和腿
- 学术先例：用深度相机预判地形切外骨骼模式，准确率 85–99%，提前量约半步到一步；**用视觉大模型做这件事的外骨骼论文一篇没有**——是空白，能当卖点，但要自己报时延
- 消费级外骨骼 + AI 的公开二次开发案例：零。Hypershell / Dnsys / Skip 都是封闭 App。你们这个开放串口固件是特供的

### D. 小屏 + 灯阵 + 麦阵：桌面/手持外设 ✅ 各自都稳

- 小屏当递给评委的"遥控器 / 徽章"，IMU 手势做输入
- 灯阵当 Agent 的表情和状态（暗场里很显眼）
- 麦阵当按住说话的近讲输入（用手柄或小屏按键当 PTT）
- 单独成不了主线，但都是给 A / B / C 加体验的件

### E. 云台手机 ⚠️ 只当彩蛋

- 让 Agent 决策后调 YOYO 技能让手机点头 / 转头看向说话的人（配麦阵 DoA）
- 读不到画面，做不了闭环感知；前置条件（账号、测试名单、固件版本）没一个确认过
- 拿不到手机也不影响主线时才值得做

## 三、明确做不到的（别在这些上花时间）

- 云台手机的画面 / 传感器回传——没有接口
- 外骨骼的实际输出力矩 / 电流——协议里没有
- 眼镜上显示文字——没有屏幕
- 现场靠远场唤醒词 / 声源追踪做主交互——噪声超出所有已知测试范围
- 眼镜实时视频当关键路径——Wi-Fi 热点在几百人现场没有任何可靠性依据
- XIAO S3 这块拍照录音——不是 Sense 版

## 四、要买的

- 一根 USB-C 数据线（手柄、麦阵都走 USB）
- 小屏要离线拿在手里：一块 JST 2.0 接口的 3.7 V 锂电

## 五、今天就该验证的（按优先级）

1. **外骨骼**：插上，`PING` → `ENABLE` → 看 200 Hz 数据出不出来 → `T,0.5,0.5` 感受一下 → `DISABLE`。试 USB-C 65 W 充电器能不能充
2. **眼镜**：先给终端授蓝牙权限；读固件版本；`luma photo --ai look.jpg` 拿到第一张小图并量分辨率；在场内喊一次 "Hi Luma"
3. **麦阵**：看板上有没有焊 XIAO；插 Mac 看出不出声卡
4. **手柄**：pygame 读一次扳机值
5. 灯阵焊排针，插 XIAO 点亮
