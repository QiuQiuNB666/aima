# 华山·长空栈道 · 专项架构（第二主打地图）

> 9/24 定：珠峰是展位默认，华山是第二张主打——评委想看「悬崖峭壁上走」「搭梯子过悬崖」就切这张。
> 负责线：H2（华山线）。数据 `shellos/worlds/huashan_plank.json`，画面 `game/themes/cliff_path.js` + `themes/cliff_path/*`。

## 1. 设计目标

1. **在悬崖峭壁上走才有感觉**：路的一侧永远是空的。峡缝里是两面夹着的窄缝，苍龙岭两边直落，长空栈道脚下就是云，鹞子翻身贴着岩壁翻上去。镜头压低、外偏，让脚下的深谷一直在画面里。
2. **建模和动作要好**：栈道是真的三块木板（30 cm 宽）架在铁桩上，踩上去会沉；铁链走过会荡；梯子踩上去微弯；金锁关的锁真的挂上去。
3. **腿上的力 = 画面上的地形**：千尺幢 / 苍龙岭 / 鹞子翻身是台阶阻力，青柯坪 / 中峰 / 落雁峰是上坡阻力，南天门是红灯（扣安全锁站定）。
4. **只读状态，不碰控制**：所有互动只读 `route.at(s)` / `state`，力只由 ShellOS 地形控制器出。

## 3. 模块分层

```
huashan_plank.json            路线（kind/steps/label/alt）── 力的唯一来源
        │
cliff_path.js  pathMaterials()/build()/update()/rigFor()
  ├─ sky.js        晴天穹顶、太阳、秦岭三层远山、云海（两层噪声平面，起风翻涌）
  ├─ rock.js       花岗岩色、绝壁（竖向节理）、巨石、摩崖刻字
  ├─ props.js      铁链 + 同心锁 + 红布条（走过会荡）、华山松、山门、栈道铁架、木板（踩沉）、安全带
  ├─ interact.js   化身旁弹的图标（和珠峰共用）
  ├─ lines.js  ★   峰哥地标台词（金锁关 / 栈道催 / 鹞子 / 登顶），走 /guide/huashan_plank_fx/<i>.wav 缓存
  └─ ladder.js ★   鹞子翻身：石窝 + 铁梯（踩弯）
```

- **地标按路段类型找（`zonesOf()`），不写死步号**：上台阶按「连着的一串」分组——第一串 = 峡缝，红灯前的串 = 山脊，红灯后的串 = 铁梯；最后一个红灯 = 扣安全锁，它后面的平路 = 栈道，前面最近的平路 = 金锁关；峡缝前的平路 = 回心石。「一句话造山」生成的 cliff_path 世界也能画。
- **溶解组**：峡缝高崖走过就溶（镜头落后 8 步在缝里不挡），山上的东西出缝才露面，栈道高崖走过就溶（登顶回头不看见比顶峰还高的墙）。
- **镜头**：按地标插值（`CAM` 表 + `camAnchors`），跟拍 / 正面一起调；栈道段 FOV +8、镜头悬在空的那一侧、压低往下看。
- **音效**：全部 `kit.sfx`（click / clink / creak / wind / ladder / chime / flutter）现合成；`?sfx=0` 静音，预览不出声。
- **峰哥**：地标台词走 `lines.js`（气泡 + 预生成语音，不走大模型）；台词清单在 §6，抄进 `guide.py` 的 `GUIDE["huashan_plank_fx"]` 跑 TTS 才出声。
