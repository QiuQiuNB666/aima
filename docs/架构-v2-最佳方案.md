# 架构 v2：山的记忆（腿部地形力反馈 + 经验继承）

> 2026-09-23 凌晨。基于三路调研（[腿部力反馈先例](../../黑客松-EvoTavern/调研/设备/腿部力反馈虚拟地形的先例.md)、[遥控他人腿部](../../黑客松-EvoTavern/调研/设备/遥控他人腿部的先例与安全.md)、[髋力矩感知阈值](../../黑客松-EvoTavern/调研/设备/髋关节力矩感知阈值与脉冲设计.md)），修正了 9/22 的口径和参数。调研原文在 evotavern-shenzhen 仓库 `调研/设备/`。

## 0. 定位（调研后的口径）

**能说的**：第一个用**消费级髋外骨骼**做**可走动**的地形力反馈——不靠地板、不靠平台，只用步态相位定时的髋力矩脉冲让人"感到"坡和台阶，并与 3D 化身同步；走过的地形和每个人的腿力偏好作为经验发布到 EvoMap，下一个人继承。

**不能说的**（有先例，评委一查就翻车）：
- "没人给腿做过力反馈 / 首个 VR 外骨骼"——Holotron（德，2020）髋+膝 150 Nm 主动力矩，演示含楼梯和斜面，但挂在固定平台上；HaptX ForceBot 龙门架；CHI 2015 Level-Ups 电动高跷靴模拟台阶；踝平台、地板弹簧、小腿风扇、踝腱电刺激都做过地形/坡度。
- "用户能分辨坡度"——2024 年电刺激研究里同一刺激不同人解读方向相反。**做完 2AFC 再报数字。**
- "Hypershell 官方开放接口"——公开渠道查不到，说"黑客松专用固件 + 串口协议"，带协议截图。

**新在哪一层**（三层同时成立，缺一不可）：穿戴可走动 × 髋单关节相位脉冲 × 消费级量产设备（约 ¥8k）。对比 Holotron：固定 / 150 Nm / 原型 vs 穿戴 / 7.5 Nm / 量产。

**科学依据**：McGrath & Sergi, ICORR 2019——髋伸脉冲在早支撑期增加推进冲量，相位定时脉冲能改变步态。上坡 = 早支撑髋伸肌矩增大（Lay 2006；Montgomery 2018：+9° 坡髋正功翻倍）。

## 2. 控制律：terrain（数字与依据）

相位约定：脚跟着地 = 0%（文献）。估计器 0 = 髋角最大（≈蹬离地），脚跟着地 ≈ 估计器 0.5（**待现场校准**：看腰部加速度冲击落在哪个相位）。

| 路段 | 脉冲 | 峰值（strength=1.5 时） | 中心 | 半宽 | 依据 |
|---|---|---|---|---|---|
| 上坡 | 伸展 | +1.5 Nm | 11%（早支撑 5–17%） | 12% | 文献：上坡增量在早支撑髋伸 |
| 下坡 | 制动（屈曲向） | −1.2 Nm | 10% | 12% | **推断**：文献说下坡是膝在吸能，髋方向未验证 |
| 上台阶 | 伸展 + 摆动期屈曲 | +1.8 / −1.2 Nm | 6% / 68% | 12% | 文献：上楼髋矩更大、髋角大 28° |
| 下台阶 | 制动 | −1.5 Nm | 10% | 12% | 推断 |

- 梯形脉冲（不是方波），宽 10–20% 周期 ≈ 100–200 ms（文献：Anklebot 100 ms、GEMS-H 200 ms）
- 摆动中段 30–60% 不加抗屈脉冲（防绊）
- 站着不动、置信度低 → 0 力（安全层门控）
- 分辨能力（文献）：时序 JND ≈2.8% 周期 → "早 5%" 可分；力矩 Weber 分数 12–19% → "±0.5 Nm" 可分；**步行时 JND 比静止大 3 倍**，所以脉冲要给足
- 峰值上限 3 Nm ≈ 0.04 Nm/kg，远低于文献扰动实验的 0.08–0.16 Nm/kg 和防跌研究的 0.2 Nm/kg

## 3. 控制律：puppet（共驾，不是接管）

- 左右摇杆上下 → 左右腿力矩，推到底 2 Nm，R2 是死人开关
- **缓升 ≥300 ms**（7 Nm/s），松开也缓降；禁止方向突变（文献：短时高力矩反而破坏平衡）
- 单段 ≤10 s，总 30 s；**被控者只能是队友**，评委只当拿手柄的 Ghost；穿的人双脚分开站、身后有椅子
- 话术："这不是接管，是共驾——你随时能抗回来。"（DigituSync：力比例可调时被控者控制感更高；Lopes 组：保留 agency 靠时机和参与）
- 观感依据：113 人调查，娱乐/VR 场景下"外力驱动身体"广泛接受；主办方自己在用 Ghost/Shell 叙事

## 4. 记忆层怎么接进地形

- 评委走完说"太陡了"→ 规则/大模型 → `strength −0.5` → 经验卡（触发条件 = 步频区间）→ 下一个步频相近的人命中
- 删卡 → 回退 → 再走回到原样（"不是写死的"）
- EvoMap：Gene = 「步频 95–110 的人，山的记忆 strength 偏好 1.0」+ 地形轨迹；validation 用 node 跑回放断言

## 6. 明天到现场必须验证的（按顺序，每项 ≤10 分钟）

1. **充满电**（USB-C 65 W；昨天疑似低电复位）
2. **力矩方向**：constant 1 Nm，正值是伸展？（数据推断是；反了改 `phase_profile.py`/`terrain.py` 符号）
3. **HS_PHASE 校准**：走 10 步，看估计器相位与腰部加速度冲击的关系；改 `terrain.py` 顶部常量
4. **强度**：terrain「台阶」，方向键调到"有感觉又不难受"，记下当缺省
5. **2AFC**：`scripts/afc.py --trials 10`，蒙眼分上坡/下坡。**≥9/10 才能说"能分辨"**；≤7 就只说"能感受到脉冲"
6. **摇杆轴号**：puppet 推摇杆没反应就把 `gamepad.py` 的 `LY_AXIS, RY_AXIS` 从 1/3 改 0/2
7. 展位前走动空间；陌生人穿戴计时；4 分钟脚本掐表

## 7. 风险与降级

| 风险 | 预案 |
|---|---|
| 脉冲感觉不到 | 强度提到 3 Nm；改用台阶（最短促）；说"触觉提示"不说"地形" |
| 相位估计在原地踏步时不稳 | 置信度门控自动归零；改成慢走 |
| 设备复位 | 自动重新 ENABLE（已做）；备录屏 |
| 主机卡顿误触发看门狗 | 已放宽到 1 s；演示机不开别的重活 |
| 2AFC 不过 | 不报数字，只演"脉冲随地形变化"，把 2AFC 当"我们诚实做了实验"讲 |
| 评委追问先例 | 主动摆 Holotron、Level-Ups、ICORR 2019，说清三层新在哪 |

## 8. 明确不做

眼镜（蓝牙权限 + 设备不在）、荣耀手机（接口无文档）、端到端策略、固件改动、蓝牙协议逆向。
