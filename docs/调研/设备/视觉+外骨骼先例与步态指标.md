# 视觉+外骨骼先例与步态指标

> 2026-09-22 调研 · 结论后附来源

**结论先行**
1. 视觉预判地形→切外骨骼模式有成熟先例，准确率 85–99%、提前量约"半步到一步"；**没找到任何用 VLM 做这件事的外骨骼论文**，这块是空白，可作为卖点但需自己给出延迟数据。
2. 康复侧看的是步速、步长/步时对称比、步时变异、双支撑期；一颗腰 IMU + 髋角就能算，公式和开源都有。
3. 偏好学习：只给"更好/更差 + 往哪调"的反馈，6 维参数 **30 次试走**可收敛（仿真约 20 次）。
4. Hypershell/Dnsys/Skip 二次开发公开案例：中英文都查不到，属于零。

**依据**

**1. 视觉 + 外骨骼**
- 髋外骨骼 + 胸前 RealSense D455，免训练地形重建，稳态识别 95.7–99.7%，过渡 87.5–100%，提前量为过渡期的 14.5–30.5%，7 人（BIT，2025）：https://pmc.ncbi.nlm.nih.gov/articles/PMC12012296/
- 髋 exosuit + RGB 相机分三种地形，每类 >85%，7 人爬楼代谢省约 20%（提前量摘要未给）：https://arxiv.org/abs/2211.15346
- ExoNet：胸前手机拍 92 万张标注图，视野在前方 1–5 m，12 类，EfficientNetB0 仅 73.2%——说明纯图像分类并不容易：https://www.frontiersin.org/journals/neurorobotics/articles/10.3389/fnbot.2021.730965/full
- 反例：Science Advances 2024 只用 IMU 估坡度（RMSE 1.3–1.9°）就能切模式，过渡步误差 10.7%：https://pmc.ncbi.nlm.nih.gov/articles/PMC11654697
- VLM：Exosense 只用 VLM 标房间名，SARO 是四足机器人；未见外骨骼用 VLM 判台阶的文献（查了 arXiv 2025–26）：https://www.alphaxiv.org/abs/2403.14320v1

**2. 垂直场景与指标**
- Hypershell 官方定位：徒步/户外/日常，非医疗：https://hypershell.tech/pages/hypershell-x-exoskeleton
- 脑卒中：APO 髋外骨骼 6 人，步速 0.83→0.97 m/s（+0.14 > MCID），步频、步长（患侧 +5.3 cm）；主指标 10MWT，量表 FAC：https://pmc.ncbi.nlm.nih.gov/articles/PMC11735669/
- 帕金森：髋外骨骼 7 人，髋 ROM +8.4%、摆动期 +4.7%、足趾离地高度 +12.3%：https://pmc.ncbi.nlm.nih.gov/articles/PMC13006675/
- 老年 + 髋外骨骼 + L5 IMU：步频、步长、步速、步时变异，ICC 0.60–0.92，用 Mobilise-D 开源算法 + 倒立摆步长模型：https://pmc.ncbi.nlm.nih.gov/articles/PMC11360760/
- 偏瘫对称性公式（L3 加速度计，24 人）：步时对称 = 患侧/健侧步时（与测力板 rho=0.83）；步长对称 = 各腿 IC 后垂直加速度积分之比：https://pmc.ncbi.nlm.nih.gov/articles/PMC5332994/
- 开源：GaitPy（腰部加速度→IC/FC、步长、步时，≥50 Hz）https://github.com/matt002/GaitPy
- 用 200 Hz 髋角可直接得：左右步时、步频、髋 ROM、步时变异；双支撑期需 FC 事件，用腰 IMU 走 GaitPy。跌倒风险量表未查。

**3. 偏好学习**
- LineCoSpar（Caltech，Atalante）：6 参数、6 人、每人 30 次试走，反馈只有两两偏好 + "某维往哪调"的协同反馈；仿真约 20 次收敛，盲测 4/6 人全部 4 次偏好命中：https://arxiv.org/abs/2003.06495 代码 https://github.com/myracheng/linecospar
- 单人在线自标注适配步态模式预测（IMU）：https://arxiv.org/abs/2603.15329
