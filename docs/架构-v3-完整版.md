### 1.1 分层与文件归属

```
┌───────────────────────────────────────────────────────────────────┐
│ 7 提交物   README · 演示视频 · 海报 · 提交表单                        │ docs/, media/
├───────────────────────────────────────────────────────────────────┤
│ 6 EvoMap   Gene/Capsule 发布 · recall/record · "用/不用继承"对照卡      │ shellos/evomap/
├───────────────────────────────────────────────────────────────────┤
│ 5 记忆·Agent 经验卡 store · 检索 · 大模型/规则解释 · 换人 · 演示复位    │ shellos/memory/ shellos/agent/
├───────────────────────────────────────────────────────────────────┤
│ 4 界面     仪表盘 server(标准库 http) · index.html · body3d.js         │ shellos/ui/
│            手柄 gamepad.py · 键盘 hotkeys.py                          │ shellos/input/
├───────────────────────────────────────────────────────────────────┤
│ 3 控制律   terrain · puppet · dofc · phase_profile · constant · transparent │ shellos/control/
├───────────────────────────────────────────────────────────────────┤
│ 2 步态估计 estimator.py（相位·周期·步频·对称·活动度·置信度·走动中）    │ shellos/gait/
├───────────────────────────────────────────────────────────────────┤
│ 1 安全层   guard.py ★ 唯一写串口的地方                                 │ shellos/safety/
├───────────────────────────────────────────────────────────────────┤
│ 0 设备     serial_link · replay · recorder · frame · convention        │ shellos/device/
└───────────────────────────────────────────────────────────────────┘
   装配：shellos/main.py（App 类 = 所有层的挂点）  脚本：scripts/  测试：tests/
```

**铁律**：任何模块只能向 Guard 提交"期望力矩"；大模型永远不在 100 Hz 循环里；每层能单独砍。

### 1.2 线程与数据流

```
串口线程 183 Hz ──► 环形缓冲(2000 帧) ──► 控制线程 100 Hz ──► Guard ──► T,l,r
                                            │  gait.update(frame)
                                            │  ctl.step(frame, gait) → (tl, tr)
                                            │  guard.submit(tl, tr, conf)
                                            └─ 每 0.5 s: auto_recall() / 状态行 / loop_ms
手柄线程 100 Hz ──► guard.set_deadman("gamepad") · ctl.sticks · on_button
网页 10 Hz 轮询 /state ──► 渲染；POST 动作走 App 方法；/hold 心跳 300 ms 失效
Agent 按需（秒级）──► interpret(quote) → 参数差值 → ctl.set_params + store.add
录制线程随串口 ──► data/recordings/<时间>-<人>.csv + .marks.csv
```

时序预算（真机实测）：控制循环最大间隔 12 ms；一拍计算 <1 ms；串口写一行 <0.1 ms。

### 1.3 状态机

```
Guard:  DISCONNECTED → CONNECTED → ARMED ⇄ ACTIVE
                                     │            deadman 松开 → T,0,0 回 ARMED（不 DISABLE，数据流不断）
                                     └─ estop / 看门狗 1 s / 退出 → DISARMED（DISABLE）→ rearm() → ARMED
Link:   enabled 由 OK,ENABLE / OK,DISABLE / ERR,NOT_ENABLED / 开机日志 维护
        needs_recovery() = 未使能 或 断流 >1 s → 主循环每 2 s 重发 ENABLE 并 guard.arm()
        拔线 → _reconnect() 每秒重开串口，最多 60 s
Gait:   静止 ──conf>0.5 连续 0.3 s──► 走动中 ──conf<0.5──► 静止
Terrain: 每个被接受的步态周期 pos+1；force 覆盖路段（2AFC/演示）
Memory: 换人 → 参数缺省、recalled=False → 走 6 步 → retrieve → 套用 → recalled=True
```

## 2. 各层规格

### 2.1 设备层（已真机验证）

- `frame.py`：`S:` 行 → `Frame(t_host, ms, pitch, roll, yaw, gx, gy, gz, ax, ay, az, kpa, l_deg, r_deg, l_dps, r_dps)`；右腿乘 `R_SIGN=-1`（真机：平放时 L −78.8 / R +77.5，镜像）
- `serial_link.py`：`/dev/cu.usbserial-*`（CP2102N，真机），3 Mbps，`timeout=0.05`；`handshake()` = PING→VERSION→ENABLE；应答计数 `replies_seen`；`enabled`、`reboots`、`needs_recovery()`、`recover()`、`_reconnect()`
- `replay.py`：同接口，按绝对时刻 200 Hz 步进；`send` 只记录
- `recorder.py`：帧 + 力矩同一 CSV；`.marks.csv` 记标签
- `convention.py`：`R_SIGN`；正力矩 = 髋伸展（**数据推断**：+3 Nm 时双髋角持续正漂，待穿上验）

### 2.2 安全层（已真机 + 单测）

| 规则 | 值 | 来源 |
|---|---|---|
| 软限 | 3 Nm 默认（≈0.04 Nm/kg） | 文献扰动实验最低 0.08 Nm/kg，我们取一半 |
| 斜率 | 0.5 Nm/拍 = 50 Nm/s | 文献 ≤150 Nm/s，梯形 |
| 死人开关 | 多来源取最大（手柄 R2 深度 / 网页心跳 / 键盘 / 回放 forced）；按压深度全局缩放 | |
| 置信度门控 | conf < 0.5 → 力矩归零（不 DISABLE） | |
| 看门狗 | 100 ms 无提交 → T,0,0；1 s → DISABLE | 固件本身 100 ms 清零兜底 |
| 断流 | 200 ms 无帧 → 归零 | |
| 退出 | atexit / SIGINT / SIGTERM / 异常 → DISABLE | |
| 急停 | × / Esc / 网页 → DISABLE，要 ○ / R / 网页重新上膛 | |

### 2.3 步态估计（真机录制回放验证，门限待真人复核）

- 极角相位：`φ = atan2(−k·ω_f, θ_f − θ̄)`，k 自适应拉圆；置信度 = 相图半径 / 8°
- 周期事件：φ 绕回，且 **0.7 ≤ 周期 ≤ 2.0 s、整周期 conf > 0.6、活动度 ≥ 15°** 才接受（修后：坐着 18 分钟 0 假周期，走路段 131 步/分、P10–P90 0.75–1.10 s）
- 走动中：conf > 0.5 连续 0.3 s
- 输出：步频、左右对称比、周期变异、活动度、`moving`、`rejected`
- **HS_PHASE = 0.5**：脚跟着地在估计器相位里的位置（估计器 0 ≈ 髋角最大 ≈ 蹬离地）——**未验证，明天用腰部加速度冲击校准**

### 2.4 控制律（统一接口 `step(frame, gait) → (tl, tr)`，`params = {name: [value, min, max]}`，`set_params(delta)` 裁剪）

**terrain（主线）**——相位按文献约定（脚跟着地 = 0%），内部加 HS_PHASE

| 路段 | 脉冲 | 峰值 (strength=1.5) | 中心 | 半宽 | 依据 |
|---|---|---|---|---|---|
| up | 伸展 | +1.5 | 11% | 12% | 文献：上坡增量在早支撑髋伸（Lay 2006; Montgomery 2018） |
| down | 制动 | −1.2 | 10% | 12% | **推断** |
| stairs_up | 伸展 + 摆动屈曲 | +1.8 / −1.2 | 6% / 68% | 12% | 文献：上楼髋矩更大、髋角大 28° |
| stairs_down | 制动 | −1.5 | 10% | 12% | 推断 |

梯形脉冲；宽 10–20% 周期（文献 100–200 ms）；摆动中段 30–60% 不加抗屈脉冲；`force` 可强制路段；预设：山的记忆 / 台阶 / 长坡。

**puppet（开场共驾）**：摇杆 → 力矩，推到底 2 Nm；**缓升 ≥300 ms**、缓降；单段 ≤10 s；被控者只能是队友（文献：短时高力矩破坏平衡；DigituSync：可调比例保留控制感）

**dofc**：`τ = ∓gain·s(t−d)`，s = 去慢均值的 (θL−θR)/2；三参数（gain 0.10、delay 0.15 s、ema 0.2）；文献 Lim 2019 代谢 −13.6%

**phase_profile**：两峰钟形（peak/t/width + 左右偏置）；**constant**：测方向/手感；**transparent**：0

### 2.5 记忆与 Agent（回放 + 单测验证）

经验卡：
```json
{"id":7,"ts":"09-23 14:02:11","wearer":"judge-03","controller":"terrain",
 "trigger":{"cadence":[95,115]},"delta":{"strength":-0.5},"quote":"太陡了",
 "confidence":0.6,"hits":2,"enabled":true,"source":"rule|llm"}
```
- `interpret()`：大模型（OpenAI 兼容，`SHELLOS_LLM_BASE/KEY/MODEL`，temperature 0，只出 JSON，差值裁剪到范围的 15%）→ 失败/未配 → 规则表（早/晚/轻/重/左腿/右腿/陡/累/没感觉/反了）
- 检索：同控制律 + 步频落在区间 + enabled；命中 delta 相加；`hits` 计数
- 换人：参数缺省、步态重估、走 6 步自动检索；删卡：若已套用则回退；演示复位：参数缺省、库不动
