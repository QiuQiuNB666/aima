## 1. 系统架构

### 1.1 分层与文件归属

```
┌──────────────────────────────────────────────────────────────────────┐
│ 6 提交物    README · 演示视频 · 海报 · 提交表单 · 评委题库               │ docs/提交/
├──────────────────────────────────────────────────────────────────────┤
│ 5 记忆·Agent 经验卡 store · 检索 · 大模型/规则解释 · 换人 · 演示复位       │ shellos/memory/ agent/
├──────────────────────────────────────────────────────────────────────┤
│ 4 界面      4a 登山游戏  /game  game.html · game/*.js                  │ shellos/ui/static/game*
│             4b 操作员仪表盘 /   index.html · body3d.js                  │ shellos/ui/static/
│             server.py（标准库 http，/state 10 Hz）                      │ shellos/ui/server.py
│             输入：gamepad.py · hotkeys.py                              │ shellos/input/
├──────────────────────────────────────────────────────────────────────┤
│ 3 控制律    terrain(主) · puppet(开场) · dofc · phase · constant · transparent │ shellos/control/
├──────────────────────────────────────────────────────────────────────┤
│ 2 步态估计  相位 · 周期门控 · 步频 · 对称 · 活动度 · 置信度 · 走动中       │ shellos/gait/
├──────────────────────────────────────────────────────────────────────┤
│ 1 安全层    guard.py ★ 唯一写串口的地方                                  │ shellos/safety/
├──────────────────────────────────────────────────────────────────────┤
│ 0 设备      serial_link(真机) · sim(模拟) · replay(回放) · recorder · frame · convention │ shellos/device/
└──────────────────────────────────────────────────────────────────────┘
   装配：shellos/main.py（App = 所有层的挂点）  脚本：scripts/  测试：tests/
```

**铁律**：只有 Guard 写串口；大模型永远不在 100 Hz 循环里；游戏和仪表盘只读 `/state`、只发动作，不碰控制；每层能单独砍。

### 1.2 三种设备模式（同一接口，上层无感）

| 模式 | 启动 | 用途 |
|---|---|---|
| 真机 | `./run-mac.sh --ctl terrain --cap 2.5` | 明天 |
| 模拟 | `--sim`：空格/网页按住走、松开停，步频可调；力矩会让髋角轻微偏移作视觉反馈 | 今晚所有线的开发和验收；展位断电兜底 |
| 回放 | `--replay 录制.csv` | 用 9/22 真机数据调步态、做压测 |

### 1.3 线程与数据流

```
设备线程 183/200 Hz ──► 环形缓冲 ──► 控制线程 100 Hz ──► Guard ──► T,l,r
                                     gait.update → ctl.step → guard.submit
                                     每 0.5 s：auto_recall · 状态行 · loop_ms
手柄线程 100 Hz ──► deadman("gamepad") · puppet 摇杆 · 按键动作
HTTP server ──► /state（游戏屏 + 仪表盘各 10 Hz 轮询）· POST 动作 → App 方法
Agent 按需（秒级）──► interpret(quote) → ctl.set_params + store.add
录制随设备线程 ──► data/recordings/<时间>-<人>.csv + .marks.csv
```

实测（真机）：控制循环最大间隔 12 ms；一拍计算 <1 ms。**游戏屏的 3D 渲染在浏览器进程里，会抢 CPU**——验收项里必须看 `loop_ms` 不上升。

### 1.4 状态机

```
Guard:   CONNECTED → ARMED ⇄ ACTIVE   （deadman 松开 → T,0,0 回 ARMED，数据流不断）
                      └ estop / 看门狗 1 s / 退出 → DISARMED（DISABLE）→ rearm → ARMED
Link:    enabled ← OK,ENABLE / OK,DISABLE / ERR,NOT_ENABLED / 开机日志；断流 >1 s 或未使能 → 每 2 s 重发 ENABLE
         拔线 → 每秒重开串口，最多 60 s
Gait:    静止 ─conf>0.5 连续 0.3 s→ 走动中 ─conf<0.5→ 静止
Terrain: 每个被接受的周期 pos+1；到顶 → laps+1、记用时、这一圈成为影子；force 覆盖路段
Memory:  换人 → 参数缺省、影子保留 → 走 6 步 → 检索套用
```

## 2. 各层规格

### 2.1 设备层

- **真机**（已验证）：`/dev/cu.usbserial-*`（CP2102N），3 Mbps，`timeout=0.05`；握手 PING→VERSION→ENABLE；应答计数、使能状态、复位计数、断流恢复、拔线重连（重连**未真机验证**）
- **模拟**（新）：`sim.py`，200 Hz，正弦髋角（左右反相，摆幅 20°），走停 0.25 s 过渡，步频 60–140；`/sim {"walk":bool,"cadence":n}`
- **回放**：绝对时刻步进；12 段真机录制在 `data/recordings/`
- `convention.py`：右腿 `R_SIGN=-1`（真机：平放 L −78.8 / R +77.5）；正力矩 = 髋伸展（**数据推断**，+3 Nm 时双髋角正漂，待穿上验）

### 2.2 安全层（真机 + 单测）

| 规则 | 值 | 来源 |
|---|---|---|
| 软限 | 3 Nm（≈0.04 Nm/kg） | 文献扰动实验最低 0.08 Nm/kg 的一半 |
| 斜率 | 50 Nm/s | 文献 ≤150 Nm/s |
| 死人开关 | 多来源取最大；按压深度缩放 | |
| 置信度门控 | conf<0.5 → 0 | |
| 看门狗 | 100 ms → T,0,0；1 s → DISABLE | 固件 100 ms 自清零兜底 |
| 断流 | 200 ms → 0 | |
| 退出 / 急停 | 必 DISABLE；急停要重新上膛 | |

### 2.3 步态估计（真机录制回放验证）

- 极角相位 `φ = atan2(−k·ω, θ−θ̄)`；置信度 = 相图半径 / 8°
- 周期接受：0.7–2.0 s、整周期 conf>0.6、活动度 ≥15°（修后：坐着 18 分钟 0 假周期；走路段 131 步/分）
- 走动中：conf>0.5 连续 0.3 s
- **HS_PHASE = 0.5 未验证**（脚跟着地在估计器相位中的位置）；**原地踏步无数据**

### 2.4 控制律

**terrain（主）**：相位按文献约定（脚跟着地 = 0%）

| 路段 | 脉冲 | 峰值 (strength 1.5) | 中心 | 半宽 | 依据 |
|---|---|---|---|---|---|
| up | 伸展 | +1.5 | 11% | 12% | 文献（Lay 2006；Montgomery 2018） |
| down | 制动 | −1.2 | 10% | 12% | 推断 |
| stairs_up | 伸展 + 摆动屈曲 | +1.8 / −1.2 | 6% / 68% | 12% | 文献 |
| stairs_down | 制动 | −1.5 | 10% | 12% | 推断 |

梯形；摆动中段不加抗屈；预设：山的记忆（37 步）/ 台阶（25）/ 长坡（39）；**每圈计时，登顶后这一圈成为影子**；`status()` 给游戏：`segments, pos, total, laps, segment, elapsed, best, last_lap, ghost_pos, ghost_who`。

**puppet（开场共驾）**：摇杆 → 力矩，2 Nm 满，缓升 ≥300 ms；单段 ≤10 s；被控者只能是队友。
**dofc / phase / constant / transparent**：备用与调试。

### 2.5 记忆与 Agent

经验卡（JSON 行）：`id, ts, wearer, controller, trigger{cadence}, delta, quote, confidence, hits, enabled, source`。解释：大模型（`SHELLOS_LLM_*`，可选）→ 规则表（早/晚/轻/重/左/右/陡/累/没感觉/反了）；检索：同控制律 + 步频区间；删卡回退；换人保留影子。

### 2.6 登山游戏（新，4a）——今晚最重的一条线

**目标**：评委不看任何曲线，只看这一屏就懂"我在爬山、腿被推了、上一个人在我前面"。

| 模块 | 规格 |
|---|---|
| 页面 | `/game`，全屏，暗色，1080p 与 4K 投屏都清楚；Three.js 本地（离线可用），`pixelRatio=1`、不开阴影，保 60 fps |
| 山与路 | 由 `terrain.segments` 程序生成：每步水平 0.5 单位；坡每步升 0.08（≈9°）；台阶每步升 0.12，用方块成阶；两侧高度场山体 + 远山剪影 + 雾；起点营地、山顶旗帜 |
| 化身 | CesiumMan，身体动画用**真实髋角**（复用 body3d 骨骼映射）；位置 = `pos` + 周期内进度（由相位插值），平滑跟随；朝向沿路径切线 |
| 影子 | 半透明第二个化身（或发光剪影），位置 = `ghost_pos`，头顶标"上一位：{ghost_who}"；领先/落后几步 |
| 镜头 | 第三人称侧后方跟随，上坡时略抬、台阶时拉近；登顶环绕一圈 |
| HUD | 海拔（米，虚拟高度 × 系数）· 第 n/N 步 · 当前路段 · **前方预告**（"2 步后：台阶"）· 左右腿力矩条（脉冲时闪）· 用时 / 最佳 · 登顶次数 · 穿戴者 · 安全状态小灯（ACTIVE 才有力） |
| 事件动效 | 脉冲 → 脚下波纹 + 路段高亮；登顶 → 旗帜、彩带、用时、"已写入山的记忆"；经验卡命中 / 新卡 → 侧边滑入卡片 |
| 输入 | 模拟模式：按住空格走、松开停，`1/2/3` 慢/中/快；真机模式由步态驱动；`R` 回山脚（= 演示复位） |
| 数据 | 只读 `/state`（10 Hz），60 fps 插值；动作只发 `/sim`、`/demo/reset`、`/terrain` |
| 验收 | `--sim` 下完整爬一圈 → 影子出现 → 第二圈影子在跑；1080p 截图 3 张（山脚 / 台阶 / 登顶）；浏览器 FPS ≥50；同时 `loop_ms` 不高于不开游戏时 +5 ms |

### 2.6.1 世界（主题）——数据驱动，加一个世界只要丢一份 JSON

`shellos/worlds/*.json`，地形控制器和游戏共用同一份。字段：`id, name, subtitle, story, note（真实性说明）, alt[起,终], route[{kind, steps, label, turns?}], summit{name,text}, theme{style, sky, fog, ground, path, accent, props}`。路段类型新增 **wait（红灯）**：走着会被轻拉、位置不前进，站定 2 s 放行。

| 世界 | 路段构成（步） | 画面 | 为什么 |
|---|---|---|---|
| **赛博东京·夜行**（默认，开场） | 平 10 · 红灯 3 · 上台阶 13 · 下台阶 5 · 上坡 6 = 37 | 霓虹雨夜、天桥、坂道、神社石阶 | 主办方攻壳主题（Ghost/Shell、未来日本）最贴；红灯停是只有城市才有的交互 |
| **泰山·十八盘** | 平 5 · 上坡 8 · 上台阶 26 = 39 | 晨光、松、云海、南天门 | 国民级；全程台阶，脉冲最明显 |
| **富士山·吉田线夜登** | 平 5 · 上坡 28 · 上台阶 7 = 40 | 星空转日出、头灯光带、鸟居 | 以坡为主，与泰山对比；国际化 |
| **深圳梧桐山·好汉坡** | 平 5 · 上坡 10 · 上台阶 20 = 35 | 亚热带绿、雾、深圳天际线 | 本地，评委"明天就能去爬" |
| 训练场·台阶 / 长坡 | 单一刺激 | 网格 | 2AFC 与调强度 |

**真实性口径**：东京是街景拼贴，不是真实连续路线；山路"按真实路段比例压缩"，海拔为约数（玉皇顶约 1545 m、富士山 3776 m、大梧桐约 944 m）。每张卡片底部都写着。
**展位用法**：开场东京（贴主题）→ 评委自己挑一座山（参与感）。
**选择页**：`/worlds`（游戏第一屏），卡片含天空、剖面、路段构成、终点；点"进入"切世界并跳 `/game`。
